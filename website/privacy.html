隐私政策

更新于 2026-10-10

语音识别与文字整理

选择本地 SenseVoice Small 时，语音识别在本机完成。选择云端识别时，录音会发送到你配置的语音服务商；启用文字整理时，转写文字和你启用的上下文会发送到文字服务商。第三方服务的数据处理规则以其隐私政策为准。

账号与同步

账号服务使用 api.opentype.top，处理邮箱、经加盐哈希保存的密码和登录会话。登录后启用同步的内容会存储在账号服务，供你的设备访问。服务所需的 API Key 保存在本机，不通过账号同步。

本地记录

转写历史、词典和偏好设置会保存在电脑上。你可以在软件中管理历史记录与同步设置。退出登录不会自动删除电脑上已有的记录。

安全验证

登录和注册使用 Cloudflare Turnstile 防止滥用。验证页面会与 Cloudflare 通信，账号密码不会传入验证页面。网站和 API 通过 Cloudflare 提供网络服务。

使用建议

处理敏感内容前，请确认当前识别方式、文字整理和同步设置。需要离线使用时，请先下载本地模型并关闭云端文字整理。
