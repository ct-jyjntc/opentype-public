不确定是哪种芯片？

Mac：点左上角苹果菜单 →「关于本机」，显示「芯片 Apple M…」的是 Apple 芯片，显示「处理器 Intel…」的是 Intel 芯片。

Windows：打开「设置 → 系统 → 系统信息」，「系统类型」写着「基于 ARM 的处理器」的选 ARM，其余选 x64。

首次打开的安全提示

macOS 版尚未通过 Apple 公证，首次打开时如有提示，请在「系统设置 → 隐私与安全性」中允许。

Windows 版尚未进行代码签名，SmartScreen 拦截时点「更多信息」→「仍要运行」。

更新说明与校验

每个版本的更新内容、全部文件和 SHA256SUMS 校验清单都在 GitHub 发布页。已安装的 OpenType 可以在「关于」中直接更新。
