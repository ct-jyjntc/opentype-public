# OpenType 0.2.0-beta.11

普通听写历史中保存的文字修改，现在可以在本机生成纠词建议。到词典页审核词条及提示，确认后才加入词典，供 DeepSeek 整理参考。支持忽略建议、查看来源、修改确认内容和从词典删除以撤销学习。个性化设置可关闭新建议生成。

建议生成不会监听其他应用的键入，也不会直接强制替换同音词。词条仍是整理参考，不会训练或修改 SenseVoice 权重；离线 ASR 的专有名词准确率不因此获得保证。明确的数字、纯标点/间距、插入删除、技术内容及大段改写会尽量跳过，短句改写仍可能成为建议，需要您审核。

未确认建议随来源历史删除；来源被重试、同步或后续修改改变时，旧建议失效。已确认词条作为独立词典内容保留，来源删除后显示提示，可另行从词典删除。重复词条不会覆盖原词典的拼写和提示。

同时修复历史编辑静默截断超过十万字的问题，并正确显示主动清空的编辑结果。候选分析超过十万字会跳过，但修改仍完整保存；超过一百万字符的编辑会明确拒绝且保留旧内容。

完整 `verify:all` 通过，新增 15 组纠词/真实数据库场景。实际 Electron 界面完成两处修改生成建议、确认一条、忽略另一条、查看来源原文及重启保留。字典进入整理请求已用模拟 DeepSeek 响应验证；真实模型纠词提升、跨应用修正检测与真人输入验收仍未完成。

macOS 13+ / Apple Silicon；继续仅内置 SenseVoice Small，无录音时长上限。ad-hoc 签名，尚未 Developer ID 签名和 Apple 公证。生产 HTTPS/邮件服务、多设备真人验收、其他平台及完整替代目标继续推进。
