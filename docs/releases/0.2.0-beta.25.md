# OpenType 0.2.0-beta.25

此版本的检查更新存在问题，已在 [beta.26](https://github.com/ct-jyjntc/opentype-public/releases/tag/v0.2.0-beta.26) 修复，建议安装新版。

- 登录、注册加入应用内安全验证，无需跳转浏览器。验证过期或加载失败时可以直接重试。
- 本地 SenseVoice 模型支持“下载并启用”，取消准备会保留原来的识别方式；多个设置窗口同时操作时会提示重新载入。
- 更新应用、菜单栏和界面图标，使显示更清晰一致。
- 下载、帮助和隐私说明统一从 OpenType 官网访问。

0.2.0-beta.24 及更早版本需要升级后才能重新登录；已有登录会话继续正常续期。不登录仍可使用语音输入，本地识别和个人云端识别密钥均保留。

此版本适用于 macOS 13 及以上的 Apple Silicon 设备，为临时签名测试版，尚未完成 Apple 公证。邮件验证码与找回密码暂未开放。
