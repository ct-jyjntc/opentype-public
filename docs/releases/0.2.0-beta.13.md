# OpenType 0.2.0-beta.13

“随便问”的回答现在先显示在卡片中。选中可编辑文字后，可以审阅回答，再点击“替换选中文字”；只读文章和只读输入框可以作为提问素材，回答可复制。解释类回答不会直接覆盖原文。普通听写继续使用结束后自动插入的流程。

替换只针对开始提问时的原选区。原文已修改、窗口关闭、历史被编辑/重试/删除或选区无法恢复时，拒绝替换并保留回答供复制。操作提交后若不能确认结果，会提示核对，不能再次点击重复发送。关闭卡片、新回答、锁屏、休眠和退出会释放旧选区。正在录音或处理时暂不替换，可以结束后再点击。

只读选区仅在“随便问”时读取，普通听写不采集只读正文。密码框仍不读取。网页上下文检查涵盖嵌入式编辑器与父页面；父页面命中黑名单时，选区和上下文不进入回答请求，卡片会提示没有使用输入环境文字。无法确认网页来源时也不附加上下文。

完整 `verify:all` 通过；新增 11 组回答卡片/选区隐私/真实数据库场景，录音会话测试增至 21 组，整理请求测试增至 11 组。真实隔离界面验证了只读框、网页正文、富文本选区、审阅后替换、原文变化保护、密码框及跨来源 iframe 的父页面黑名单。

界面测试使用合成语音指令与固定回答，选区获取、卡片、替换和验证走真实原生桥；不代表真人语音或模型回答质量已验收。测试版仍仅内置 SenseVoice Small，无产品录音时长上限。macOS 13+ / Apple Silicon；ad-hoc 签名，尚未 Apple 公证。第三方复杂编辑器、实体键盘/麦克风、生产服务和完整替代目标继续待验收。
