# OpenType 0.2.0-beta.9

新安装默认保持本地使用，不再预填旧公网账号地址。账户页会提示配置有效的 HTTPS 服务，保存前不允许提交登录；本机回环开发服务仍可使用 HTTP。

登录、刷新、同步、语音和配套服务转发已统一验证地址并拒绝凭据请求重定向。自定义语音服务不会取得另一服务的账号令牌；更换语音服务地址会清除未重新提供的旧 API Key。修复退出后旧刷新恢复账号、旧登录覆盖新登录的竞态；邮件日志不再输出验证码或收件人。

继续保留 SenseVoice Small、停顿预识别、无录音时长上限、短按/长按录音和可选云端按条删除。

完整自动化验证通过，新增客户端 15 组、服务端 4 组网络检查。没有放宽 TLS 证书验证，没有发送真实邮件或操作用户真实账号。

macOS 13+ / Apple Silicon。ad-hoc 签名，尚未 Developer ID 签名与 Apple 公证。云端功能仍需自行配置已升级且具有有效 HTTPS 的服务；本次没有部署线上服务。真人与真实多设备验收、中文偏好与纠词学习等仍未完成。
