# OpenType 0.2.0-beta.10

个性化设置新增中文标点、中英文与数字间距。格式调整在本机执行，关闭 DeepSeek 文字整理或断网时仍可使用；默认保持识别/整理结果，仅作用于普通听写。历史详情继续保留识别原文。

新增默认表达方式和按应用语气规则：保持原语气、简洁、正式、自然口语。语气与额外写作偏好需要开启个性化和 DeepSeek 整理；没有整理服务时不会假装已经改写。规则使用开始录音时的目标应用，历史重试按原目标应用和当前设置处理。常用应用及最近 500 条历史中的应用可选择，最多保存 50 条规则，浏览器不区分网站。

修复历史重试等待个性化数据时可能切换到另一识别服务的问题。普通录音与停顿预识别都走同一最终格式处理，不在录音期间插入、不重复插入。

完整 `verify:all` 通过；真实 SenseVoice Small 的整段、增量和历史重试在离线整理关闭状态下验证通过。实际 Electron 界面完成保存、退出重启保留和移除规则检查。真实模型样本为 macOS 合成语音，尚不代表真人麦克风与跨应用插入验收；DeepSeek 语气规则的请求测试使用模拟响应，不代表真实改写质量。

继续只内置 SenseVoice Small，保持停顿预识别、无录音时长上限和此前快捷键/数据/网络修复。macOS 13+ / Apple Silicon，ad-hoc 签名，尚未 Developer ID 签名与 Apple 公证。生产服务、自动纠词学习、真实多设备及其他平台仍未完成。
