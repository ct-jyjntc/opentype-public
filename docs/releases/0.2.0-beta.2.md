# OpenType 0.2.0-beta.2

此测试版的实际界面已切换为完整可编辑源码：React、TypeScript、CSS。保留原有侧栏、历史/词典和设置弹窗的布局，新增本地免登录入口、首页听写测试、词典本地操作及明确填写的写作偏好。首次引导、浮窗和回答卡片也由源码构建。

录音会话等待 AudioWorklet 尾包后保存 WAV，随后调用原生 SenseVoice；失败保留录音供重试，取消不会迟到插入。修复 Fn 组合键的模式抢占、Esc 取消、托盘停止。新安装默认 SenseVoice，已有配置保留。

验证：完整 verify:all、包内 WAV/Ogg 原生模型推理、取消/重启/空闲恢复、严格代码签名校验均通过。Electron 实际界面与固定语料录音、播放、重试、源码热更新已走查。真人物理热键/麦克风、多屏和跨应用验收待测试者反馈。

安装：退出旧版，将 DMG 内的 OpenType 拖到应用程序替换。保留用户数据目录。macOS 13+ / Apple Silicon；采用 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。
