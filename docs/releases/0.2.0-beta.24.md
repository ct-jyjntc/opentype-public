# OpenType 0.2.0-beta.24

整合前端 PR #2 的开关、紧凑布局和精简文案，并在首次引导中加入识别方式配置。继续前检查云端 Key 或本地模型是否已准备好；保存失败和窗口间配置冲突不会跳过，保存期间不能退回上一步。云端语音、本地 SenseVoice 和可选文字整理均保留。

登录、注册、令牌刷新、历史同步与词典同步固定使用 `https://api.opentype.top`。账户页不再提供服务器地址输入；识别与文字整理的个人 API Key 独立管理。账户初始加载失败可重试，登录注册期间禁止重复提交或切换表单，退出和同步失败显示错误。

旧自定义账户服务的会话在迁移时清除，旧历史与词典保留在本机并继续与原服务隔离，不会自动上传给官方新账号。登录本身不会启用历史或词典同步。

截至 2026-10-10，官方源站已部署本版本代码，使用 Node 24 LTS、专用 nginx 与 Let's Encrypt 证书；`api.opentype.top` 已启用 Cloudflare 代理和该主机限定的严格 TLS、不缓存规则。独立公网检查确认 HTTPS 健康响应正常，无效登录返回 401，账号响应为 DYNAMIC/no-store。邮件通道尚未配置，邮箱验证码和找回密码暂不可用；密码注册、登录不依赖邮件。

独立审查已检查隔离客户端的账号界面、旧配置迁移，并用隔离数据库与合成账号验证真实 HTTP 的注册、登录、刷新轮换、会话撤销及同步隔离。最终安装包使用全新隔离配置，实际完成官方服务注册、看到同步关闭和零历史、退出、再次密码登录。

公网生产接口另用两个合成账号验证：未开启同步时上传被拒绝；开启后，账号 A 拉回的历史文本和词条与预先提交的内容一致，账号 B 均为空；退出后旧令牌被拒绝，密码重新登录成功。所有这些路径由非功能作者的审查者执行，合成账号随后清理。生产未单独重做刷新重放，不能将本地结果扩大为该项公网验证。

Apple Silicon 的 DMG/ZIP 已从公开主分支 `0886698` 构建，保留本地模型；安装包为临时签名，未公证。源码、公开 Git 历史和安装包内容检查未发现真实凭据；扫描中的第三方源码与变量告警已逐项复核，此检查不构成穷尽保证。真实麦克风、跨应用输入、多设备真人复测、更新下载安装和 Windows 构建未由本次变更验证。
