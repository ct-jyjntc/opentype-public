# OpenType 0.2.0

首个正式版，包含 beta.26 之后的全部改动。

## 新功能

- 支持 Apple 本机语音识别，可在“听写模型”中选择，并可单独指定识别语言。
- 修改识别结果中的词后，会提示是否把改后的词加入语音词典。
- 识别语言设置对本地 SenseVoice 生效，录音中的提前识别同样使用该语言；云端 SiliconFlow 始终自动识别语言，设置页会注明。

## 改进

- 文字写入改用与 VocaMac 相同的方式：只要录音开始时的应用仍在前台就写入，Edge、Chrome 等网页输入框不再报“无法读取输入框焦点”。录音期间切到其他应用则不粘贴，文字保存在历史中。
- 写入后剪贴板原内容会恢复，并标记为临时内容，剪贴板管理工具不会多出重复记录。
- 锁屏或睡眠时，已录下的内容会继续识别并保存，不再被丢弃。
- “外观”对答案卡片与听写模型设置窗口同样生效；“在 Dock 中显示应用”重启后仍然保持。
- 写作偏好未启用或缺少 DeepSeek 密钥时，相关设置会置灰并提示。
- 错误提示更准确，原先直接显示内部代码的情况改为中文说明。

## 修复

- 按住说话时同时碰到左右同名修饰键（如左右 Command），松开后录音无法结束。
- 打开主窗口时反复弹出辅助功能授权提示。
- Shift + 字母或数字可被设为快捷键，导致正常打字时触发录音。
- 停顿后很短的结尾语音偶尔使整段识别失败。
- 未开启同步时产生的历史，可能被之后登录的其他账号上传；云端拉取可能覆盖本机尚未上传的修改。
- 输入框周围的文字与选中文字不再随历史上传到云端。
- 应用窗口不再能被拖入的链接或文件导航到外部页面。

此版本适用于 macOS 13 及以上的 Apple Silicon 设备，为临时签名，尚未完成 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。邮件验证码与找回密码暂未开放。

文字写入代码来自 [VocaMac](https://github.com/VocaHQ/vocamac)（AGPL-3.0），自本版本起 OpenType 以 AGPL-3.0 发布。
