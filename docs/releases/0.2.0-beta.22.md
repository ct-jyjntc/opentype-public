# OpenType 0.2.0-beta.22

日期：2026-10-09。本轮整合 旧仓库 PR #2 的前端优化，继续专注语音输入，保留 SenseVoice Small、自然停顿提前识别、不限总录音时长和安全文字写入。

- Skills 移至侧栏独立页面：首页仍可切换当前 Skill；新建、编辑、排序、导入导出和文字工作台保留，自动应用范围按需展开。
- 历史详情的恢复原文、重新识别、导出录音和删除收进“更多操作”，删除仍需确认。
- 统一图标与中性色，调整设置分组、权限状态、模型状态、账户、帮助及关于页面；引导增加步骤说明和返回入口。
- 录音浮窗简化为胶囊，听写、翻译、随便问分别用白、蓝、绿区分；保留停止和取消按钮，不再显示计时和中间转写预览。这不改变长录音识别机制。
- 回答卡片随内容调整高度，长答案在卡片内滚动，继续保留复制、选区处理及显式替换操作。
- 延续紧凑布局、浅深主题及统一滚动条，本轮各主要页面的实际可用性以独立运行记录为准。

独立审查发现并修复两处回归：历史更多菜单按 Esc 现在仅关闭菜单，保留未保存草稿并还原焦点；胶囊恢复断麦和音量控制提示，保留简短标签与完整悬停说明。另修复纯键盘离开菜单后，后台菜单可能抢占编辑弹窗焦点的问题。历史草稿与键盘离焦路径已取得独立真实界面证据；断麦告警通过具体代码反例和独立源码复核，未实际制造设备故障。

PR #2 已合并入 `main`，交付源码为 `d723f3c54cc29e1e67a28b1668938920b572cc07`，源码树与已审查的修复提交 `a73f1bd6ab5ca2e8f4cb914dcae35a46461e40ce` 一致。类型检查、主进程和渲染层构建完成。原生源码及相关构建配置未变，复用 beta.21 原生组件；SenseVoice Small 及无拼音、无 Whisper 的打包配置保留。macOS arm64 DMG/ZIP 已生成，深度严格签名、DMG/ZIP 完整性及包资源检查通过。包内含五个语音 helper 和 SenseVoice Small，没有拼音、Rime、IMK、TSF 或 Whisper 组件；包内程序与已构建产物匹配。独立运行代理已将最终 DMG 只读提取，以合成 QA profile 启动包内应用；实际进入 Skills 显示 9 条项目，关于页显示 `0.2.0-beta.22`（[Skills](../../tmp/qa-beta22/runtime-06-package-skills.png)、[版本](../../tmp/qa-beta22/runtime-07-package-version.png)）。详见 [测试状态与真人清单](../testing/OpenType-0.2.0-beta.22-测试结果.md)。

独立界面还确认 Skills 副本保存后列表从 8 项变为 9 项、历史草稿保存后回读一致，以及默认窗口滚至底部后仍可打开副本菜单。精确 780×580 窗口、深色主题、首次引导、模型独立窗口及回答卡片真实高度未完成本轮运行验收。

交付 macOS Apple Silicon 测试包，使用本地 ad-hoc 签名，未公证；不发布 GitHub Release。Windows 本轮没有编译、运行或安装包。物理快捷键、真人麦克风、长时间录音及第三方应用兼容性仍需按清单复测。
