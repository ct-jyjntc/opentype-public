# OpenType 0.2.0-beta.8

历史删除新增可选的云端及同步设备范围。删除任务断网和重启后保留，账号与服务器隔离；设置页显示待云端确认数量。旧设备的迟到上传不能恢复已删除记录。

修复增量同步跳过记录、云端元数据下载落库失败和来源不明旧记录的自动认领问题。继续保留 SenseVoice Small、停顿预识别、无录音时长上限和短按/长按操作。

完整自动化验证通过，真实客户端/隔离服务端联调 14 组、同步回归 18 组通过，实际界面核对了删除范围与待删除数量。

**云端新能力需要更新服务端并配置 HTTPS；本次没有部署线上服务。** 旧服务不支持时保留任务并报错，不会冒充删除成功。当前默认公网 HTTP 地址将被同步模块拒绝；本地听写不受影响。

macOS 13+ / Apple Silicon。ad-hoc 签名，尚未 Developer ID 签名与 Apple 公证。未替换已安装应用或操作真实历史。真人麦克风、物理快捷键、跨应用输入、真实多设备及生产服务仍需验收，完整替代目标尚未完成。
