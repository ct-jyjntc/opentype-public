# OpenType 0.2.0-beta.5

本地听写现在会在录音过程中利用自然停顿提前识别，停止后补齐尾段及尚未完成的任务，再输出完整文字。默认仍是 SenseVoice Small int8；未增加模型，也没有录音时长限制。

应用根据连续低音量判断停顿，保留所有音频采样。短暂停顿会继续积累；长时间持续讲话则使用最长约 25 秒的内部窗口。后台识别串行执行，避免多个本地推理相互争抢；已完成片段不会在停止时重复识别。DeepSeek 整理、翻译和语音指令均在全文合并后执行一次。

音频消息携带录音会话标识，拒绝旧录音残留和停止确认之后的迟到音频。取消会终止在途识别、清理待处理片段，旧结果不会插入或污染下一条录音。后台失败的片段会单独重试一次；持续失败保留完整录音供重试，不输出缺失片段的文本。

本机真实 SenseVoice 测试：36 秒中文合成语音按实际时长送入，停止前完成 5 段，停止后只补第 6 段；关闭文字整理时，停止到返回文字由约 0.67 秒降为 0.14 秒，减少约 79%。增量测试包含模型冷启动，对照使用已加载模型。这是单次本机测试，不含实体麦克风、系统插字及云端整理耗时，不能代替真人测试。

安装：退出旧版，再将 DMG 内 OpenType 拖入“应用程序”替换。macOS 13+ / Apple Silicon，ad-hoc 签名，未 Developer ID 签名及公证。

真人复测参照 [边录边识别测试](../testing/OpenType-0.2.0-beta.5-边录边识别测试.md)。
