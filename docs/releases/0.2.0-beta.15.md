# OpenType 0.2.0-beta.15

补齐设置 → 账户中的云端保留时间和清空云端历史。支持永久、90 天、30 天、7 天，缩短保留期会先确认。按首次到达服务器的时间计算年龄，编辑或重新上传不会延长期限；服务启动、每分钟和读取/上传时都会检查到期数据。

到期或整体清空只移除云端副本，本机文字和录音继续保留。已清理的记录不会自动重新上传。“删除单条历史并同时删除云端”仍会把删除传播到其他设备，二者含义不同。

清空请求会在本机保存唯一编号，断网或响应丢失后显示“确认上次清空结果”。重启后重试同一次请求，不会重复删除之后新上传的记录。各设备得知清空时已有的本机记录将仅留本地，包含离线期间未同步的记录；此后新录音仍可按同步开关上传。保留期放宽也不会恢复旧云端副本。

新增 12 组真实客户端/服务端生命周期测试、4 组数据库迁移与事务测试，同步场景从 18 组增至 25 组；完整 `verify:all` 通过。隔离的实际前端确认、取消、失败提示、重启及重试检查通过。测试未操作真实用户账户，未部署线上服务。

云端新功能需要同时升级服务端；旧服务会禁用这些控件并显示升级提示。本地听写保持 SenseVoice Small、自然停顿提前识别和无产品录音时长上限。

安装包：macOS 13+ / Apple Silicon，ad-hoc 签名，尚未 Apple 公证。真人语音质量、跨应用兼容性和整体替代验收继续进行。
