# OpenType 0.2.0-beta.3

修复全局快捷键监听失效：监听被系统暂停后保留回调自动恢复，启动授权检查和监听状态可见，设置页可重新连接。支持保存右 Command 等物理单修饰键并区分左右；单修饰键松开触发，避免 Cmd+C 意外开始录音。补齐数字键和 Fn+Shift 的按键顺序处理。

完整 `npm run verify:all` 与独立原生键盘回归测试通过。原生测试覆盖两次真实 tap 禁用/恢复以及 8300 次回调启停。已走查设置保存与状态显示；真实键盘、跨应用和睡眠验收请按随包清单完成，尚未以真人测试判定通过。

退出旧版，将 DMG 中的应用复制到“应用程序”替换，用户历史与配置保留。在系统设置检查 OpenType 的输入监控、麦克风与辅助功能权限；输入监控列表为空时可用加号添加 `/Applications/OpenType.app`，随后回应用重新连接。

macOS 13+，Apple Silicon。含本地 SenseVoice Small int8 模型。采用 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。
