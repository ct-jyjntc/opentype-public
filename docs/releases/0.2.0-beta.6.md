# OpenType 0.2.0-beta.6

本版修复本机历史记录与录音删除不一致的问题：删除记录、清空和到期清理会同时清理对应录音；后台写入与识别不能让已删记录重新出现。临时清理失败会提示并保存待办，重启后继续处理。缩短保留期立即生效。

延续 beta.5 的 SenseVoice Small 本地停顿预识别、全文合并后一次整理，以及无产品录音时长限制。Whisper 不包含在本版中。

完整 `npm run verify:all` 通过，新增 11 组真实临时数据库/文件回归，并验证桌面重试期间删除不会恢复记录。Chatterfly 与 Typeless 的本机功能核对见配套对照文档；不据此宣称已经完全替代两款产品。

本机删除尚不会逐条删除云端副本，也未清扫升级前已成为孤立文件的旧录音。本版没有替换您的已安装应用或操作真实历史。

安装：macOS 13+ / Apple Silicon。退出旧版后，将 DMG 中 OpenType 拖入“应用程序”。本包为 ad-hoc 签名，未完成 Developer ID 签名及 Apple 公证。请使用配套真人复测清单逐项验收。
