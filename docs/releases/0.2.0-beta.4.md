# OpenType 0.2.0-beta.4

快捷键设置改为直接按键录入：点击快捷键按钮后，按右 Command、Fn、F8 或组合键，候选值会立即显示。录入期间暂停听写快捷键；保存、取消、Esc、切出窗口、关闭窗口或渲染进程退出都会释放录入状态，避免弹出听写胶囊或留下禁用状态。

本地识别只保留 SenseVoice Small int8。移除 Whisper 选项、长录音/语言/错误自动回退路径；旧的本地模型配置启动时迁移到 SenseVoice。支持普通话、粤语、英语、日语和韩语。DeepSeek 仍是可选的文字整理服务。

移除 0.4 秒最短录音、30 秒本地解码限制及 9 分钟自动停止。长音频内部按停顿分段识别并合并，始终使用 SenseVoice；分段长度不限制总录音时长。推理进度会刷新故障看门狗，不再把 30 秒当成整条长录音的处理截止时间。空音频和真正停滞的推理仍会明确报错。

验证：完整 `npm run verify:all` 通过；真实 SenseVoice WAV/Opus、75 秒以上的连续测试音频、短录音、超过 9 分钟的会话与解码测试通过。真实界面已验证按键录入、候选替换、组合键保存、Esc 取消和仅显示 SenseVoice。原生右 Command 事件进入录入器且不触发录音的测试通过；实体键盘单独右 Command/Fn、跨应用与实际长时间麦克风录音仍需真人复测。

安装：退出旧版，将 DMG 内的 OpenType 拖入“应用程序”替换。已有配置与历史保留。macOS 13+ / Apple Silicon；ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。
