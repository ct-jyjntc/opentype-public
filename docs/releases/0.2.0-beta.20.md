# OpenType 0.2.0-beta.20

日期：2026-10-09。本轮调整页面整体比例及滚动条，使首页、设置与列表在桌面窗口中更紧凑，并统一可滚动区域的外观与操作反馈。主进程/渲染层编译及类型检查已完成；源码提交 `74e95f818a212aabfc6e372bee868197e6b20b7f` 已先推送远端 `main`，随后从该提交构建安装包。独立源界面验收已覆盖默认、最小和宽窗口，深/浅主题、设置滚轮、主区域纵向拖动与长代码横向拖动；macOS arm64 DMG 与 ZIP 已生成，最终 DMG 提取 app 已确认默认窗口新布局、滚轮滚动、导航和 SenseVoice 文件校验就绪。

- 收紧页面标题、侧栏、卡片间距和首页统计栏，保留正文的阅读字号；窄窗口将右栏移到下方。
- 为所有渲染页面提供共享的浅色/深色滚动条，覆盖纵向和横向轨道及悬停/拖动反馈。
- 调整页面、设置、回答卡片及音频管理的滚动容器，减少受限高度中的嵌套滚动与不可达内容。
