# OpenType 0.2.0-beta.19

日期：2026-10-09。此版本整合 PR #1 的前端更新，并修复审查发现的词典长词重叠、首页统计口径与隐私说明问题。已从源码提交 `e0528858dfc3a785394db40ebe0040d504346b2c` 编译打包；独立交付包验收已确认词典长词换行、混合历史统计与隐私说明。

## 本次变化

- 更新首页、侧栏、场景卡片、统计、历史标签、设置及听写浮窗外观，保留浅色与深色主题。
- 词典内的长英文词汇及读音提示可在各自列内换行，避免覆盖相邻内容和操作按钮。
- 首页将全部记录的指标标为“录音时长”“输出字数”“历史记录”；口述速度与估算省时使用成功听写的原始文字和相应录音时长，缺少有效数据时显示“—”，并说明估算口径。
- 隐私说明分别列出 DeepSeek 文字处理和可选云端同步的数据发送行为。

保留 SenseVoice Small、本地识别、自然停顿提前识别和不限总录音时长；不包含 Whisper。本次未修改语音识别、快捷键或系统拼音实现。

真实包内路径：在默认 1080×720 深色界面保存长英文词汇和提示，两列各自换行；7 条混合历史显示 240 字/分及省时 1 min，在历史表单将一条输出从 60 字改为 1000 字后，总输出从 5265 变为 6205，速度和省时保持不变。长读音实际追加 `Updated` 并保存成功；包内 SenseVoice 对一次中文合成音频给出预期句子。这些结果不代表完成全部主题/窗口尺寸或真人语音链路验收。
