## 本轮内容与验证范围

版本包含此前累计的 Windows/macOS 源码功能，保留 SenseVoice Small 和自然停顿提前识别，不设置录音长度上限。本轮还修复了服务端词典改名后公开 ID 改变的问题，并完成应用/服务端类型检查、主进程/渲染层和 macOS 原生构建。

真实验收观察：首页、设置和 Skills 可打开；F8 与组合快捷键可录入；当前 F8 在录入模式下不启动听写；重启后快捷键、自定义 Skill 和模型就绪状态保留。包内模型对真实中文 WAV/Opus 给出预期文字，超过 75 秒音频也完成识别。

当前未生成 Windows 安装包：本机缺少 Windows SDK、MSVC 和 Windows 运行环境，Windows 代码仅完成独立源码审查。macOS 系统拼音安装和语音交接、物理右 Command、真实麦克风及跨应用自动输入仍需用户实机验收。

既有应用检查脚本 27 组中 25 组成功、2 组旧 fixture 失败，未改写测试掩盖失败。服务端 215/215 的历史脚本记录仅作变更探针；词典协议另有独立 localhost HTTP/SQLite 行为复核。完整证据和手动步骤见[测试结果与真人复测清单](../testing/OpenType-0.2.0-beta.18-测试结果.md)。
