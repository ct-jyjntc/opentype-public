# OpenType 0.2.2-beta.4

本测试版改进光标上下文听写和安全投递，并加入 Windows 窗口控件及剪贴板恢复修复。

## 改进

- 语音输入可以利用光标附近的文字辅助润色。仅在明确的自然语言句尾允许将句末标点改为逗号；数字、代码、链接、空白和已有选区保持原样。无法安全改写时只插入识别正文。
- Windows 窗口提供最小化、最大化和关闭控件；macOS 保留系统原生标题栏控件。各平台隐藏滚动条时仍可滚动内容。
- Windows 剪贴板恢复会检查剪贴板是否已被用户更新，避免恢复旧内容覆盖较新的复制内容。
- 本地 SenseVoice 资源使用固定版本和 SHA-256 校验。Windows beta 安装包由 Windows runner 根据本次发布提交和当前原生源码构建。

句尾安全改写已通过 macOS 真实文本框验收；Windows 窗口控件和剪贴板恢复由 Windows 开发者实测，详细覆盖范围以对应验收记录为准。此版本适用于 macOS 13 及以上的 Apple Silicon 设备，使用临时签名，尚未完成 Apple 公证。安装或更新后，系统可能需要重新授予麦克风、辅助功能与输入监控权限。Windows beta 为 x64 NSIS 安装包。
