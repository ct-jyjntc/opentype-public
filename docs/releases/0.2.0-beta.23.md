# OpenType 0.2.0-beta.23

新增 SiliconFlow 云端 SenseVoice Small 识别，新安装默认选择云端；既有配置保持原识别方式，本地 SenseVoice Small 仍可选择。云端模式通过官方音频转写接口按片段上传录音，需要网络与用户自己的 SiliconFlow API Key；保留自然停顿提前识别和无产品总录音时长限制。

在“设置 → 听写模型”选择识别方式，填写、替换或清除云端密钥，并保存。未保存的修改会明确提示。SiliconFlow 与文字整理密钥分别保存，配置回读只返回是否已保存，不返回密钥；不随设置备份导出。启用云端整理时，识别文字和允许的文字上下文仍会发送至整理服务。

合入前端 PR 的紧凑黑色录音胶囊与简化关于页，保留正常完成后快速收起。更新检查源改为公开仓库 `ct-jyjntc/opentype-public`；测试版开关以实际保存的频道为准，避免并发点击显示错误频道。

本次 macOS Apple Silicon 测试包由产品提交 `d8fc9ab` 构建，使用 ad-hoc 签名，未公证。后续维护说明只更新文档，不改变包内产品代码。没有发布 GitHub Release，也没有安装到用户应用目录。

独立审查者 `integration_hacker` 未编写本次产品功能，使用隔离配置与合成语音完成以下实际路径：

- 系统合成 WAV 经实际 `SiliconFlowProvider` 调用官方接口，返回“今天下午3点开会，请提前10分钟到达会议室。”；两个片段的边录边识别按序输出完整两句，未重复或丢段。
- 包内 SenseVoice worker 使用包内模型识别同一合成 WAV，输出相同测试句，保留可用的本地选择。这不代表真人麦克风到输入框的完整路径已验。
- 实际界面验证新配置默认云端，以及本轮合成配置中明确保存的本地选择在重启后保留；测试占位密钥经 UI 保存后加密落盘，退出重开仍显示已保存，清除后磁盘值为空。它不是有效 API 凭据，也不用于识别成功结论。
- 主窗口与独立设置窗口的未修改页面会同步另一窗口保存的识别方式；有草稿时的冲突阻止逻辑仅经独立代码审查。
- provider 请求发出后中止返回 `success=false, detail=cancelled`，不等于全局快捷键取消路径已验。
- 实际关于页显示 beta.23，并验证测试版开关；检查新仓库时因尚无 Release 显示可见错误。尚未验证更新下载和重启安装。
- 最终 DMG 以只读方式挂载，包内 `app.asar` 与运行验收的应用 `app.asar` SHA-256 一致。

审查中修正了通用存储桥读取敏感配置的绕过路径、首页错误的“识别都在本机完成”文案，以及两个设置窗口之间的草稿覆盖风险。

源码候选及公开提交历史扫描未发现密钥。最终安装包解包扫描的 8 条通用密钥告警经逐条复核，均为快捷键计数表达式、SQLite 函数宏或常量比较；未识别到实际凭据。包清单未见用户配置、录音、数据库或项目临时验证文件。扫描不等于对任意二进制内容不存在秘密的绝对证明。

真实麦克风录制、物理快捷键与 Esc 取消、跨应用自动输入、多分钟或数小时长录音、实际断网/限流/额度耗尽/多段失败恢复、替换密钥的错误回滚、双窗口有草稿的冲突分支，以及 Windows 编译运行仍未验。没有 provider 字段的早期配置迁移仅经代码审查。模拟音频采集受 Chromium sandbox 限制而未成功，不计作麦克风或跨应用路径通过。
