# OpenType 0.2.0-beta.17

本轮修复安装后模型就绪与恢复流程。首次启动先显示界面，再在后台校验并准备安装包内的 SenseVoice Small；这一步不联网。设置页改为“准备 / 修复模型”，优先使用安装包，仅在所需文件缺失或损坏时尝试下载。

模型状态会重新核对文件身份。词表丢失、模型被修改后，不再继续显示“已就绪”；普通识别和停顿分段识别共用校验入口。安装、导入与检查相互协调，避免重复操作覆盖文件。准备过程可取消，失败保留可重试提示。模型尚未就绪时也能保存关闭 DeepSeek 整理等设置。

支持显式 `--user-data-dir=<绝对路径>`，用于独立配置的排查和安装验收；配置、数据库、模型、浏览器缓存与日志使用所选目录。这类启动不注册默认深链接处理器。正常启动仍使用原数据目录；开发测试环境变量在打包程序中仍不生效。第二实例未取得锁时不再进入初始化流程。

完整 `npm run verify:all` 通过，新增 16 组模型和数据目录测试。实际从 DMG 复制的、未修改的应用通过首启、引导、模型修复、第二实例退出、正常退出和重启检查，并经真实历史重试入口完成合成音频的 SenseVoice 识别。另在操作系统禁止联网的 Node 环境中验证了包内模型安装与修复；包内 worker 的 WAV/Ogg、75 秒以上合成语音、取消与空闲释放测试通过。

图形程序验收没有强制断开系统网络；外层沙箱与 Electron 自身沙箱冲突，因此离线模型验证单独进行。未迁移真实用户数据，也没有替换 `/Applications` 中的应用。真人语音、第三方输入框、首次系统授权、实际原位升级与在线服务仍需验收。

适用于 macOS 13+ / Apple Silicon，ad-hoc 签名，尚未 Apple 公证。仍仅保留 SenseVoice Small、自然停顿提前识别和无产品录音时长上限。整体替代目标继续进行。
