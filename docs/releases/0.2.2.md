# OpenType 0.2.2

本版把 0.2.2 beta 系列的听写、光标上下文改写和文本投递改进作为稳定版发布，并提供 macOS 与 Windows 的 x64、ARM64 安装包。Windows ARM64 包含本地 SenseVoice 离线识别运行库。

## 改进

- 语音输入可用光标附近的文字辅助润色；遇到数字、代码、链接、空白或已有选区时保持原文，只在明确的自然语言句尾进行安全改写。
- Windows ARM64 提供与 x64 相同的本地 SenseVoice 离线识别能力，无需把音频发送到云端。
- Windows 安装包按 x64 和 ARM64 分开构建，macOS 安装包分别面向 Intel 与 Apple Silicon。

## 安装说明

Windows 和 macOS 安装包尚未使用可验证的发行者签名；macOS 版本也未完成 Apple 公证。系统可能显示安全提示。首次安装或更新后，可能需要重新授予麦克风、辅助功能与输入监控权限。
