# OpenType 0.2.1

## 新功能

- 支持在“关于”中直接下载并安装更新：下载后校验文件完整性，安装失败会自动恢复原版本，下次打开时在“关于”中说明原因。从 0.2.0 升级需要手动安装本版本一次，之后即可在应用内更新。

## 改进

- 账户页更紧凑：登录、注册与安全验证放在同一列，已登录时一行显示同步状态与操作，不再需要滚动。
- 安全验证组件按标准尺寸完整显示，不再被裁切或出现滚动条。
- 更新下载显示进度条与已下载大小。
- 引导页在最小窗口下无需滚动；Apple 识别使用正确的 Apple 标志，状态与报错不再互相矛盾。
- 侧边栏去掉“Beta”标记。

此版本适用于 macOS 13 及以上的 Apple Silicon 设备，为临时签名，尚未完成 Apple 公证。临时签名的应用每次更新后，系统可能需要重新授予麦克风、辅助功能与输入监控权限，并在首次启动时询问是否允许访问钥匙串。邮件验证码与找回密码暂未开放。
