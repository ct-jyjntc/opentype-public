# OpenType 0.2.3

日期：2026-10-18

本版聚焦输入交付稳定性、隐私一致性和发布工程质量。

## 改进

- 合并 Chromium/Electron 辅助功能树初始化重试、预期进程绑定、窗口焦点兜底和瞬时 AX 错误重试，减少首次听写或粘贴后短暂无法核验的问题。
- 完成胶囊保持短显示：普通完成约 300 ms、带通知约 1.4 s；无法确认粘贴但可能已成功的状态不再显示黄色提示，其他真实交付错误仍正常显示。
- 移除输入框修改检测和浮动栏胶囊纠词提示，保留历史纠错与手动词典。升级时会清理未审核的旧输入框建议，不删除已确认词条及其来源。
- 修复 CSV 导入中重复词条覆盖已有发音提示的问题；重复项保留第一条，已有词典项不被覆盖。
- 服务端敏感域名黑名单已接入客户端，并在启动及每小时刷新；网络失败时继续使用最近一次有效列表。
- 隐私页明确披露 SiliconFlow 云端音频上传、本地识别、文字整理和历史同步中的上下文元数据范围。
- 长录音 WAV 编码减少一次完整中间副本，并在编码完成后尽快释放原始音频块。
- macOS 安装包只保留当前架构的 Koffi 二进制，减少无效体积。
- 服务端定期清理过期 refresh token、授权码、邮箱验证码和密码重置码。

## 工程与安全

- `drizzle-orm` 升级到 `0.45.4`；生产依赖审计结果为 0 漏洞。
- 修复认证、润色、录制控制、输入交付、服务端同步默认值和已下线页面相关的测试漂移。
- 默认测试不再包含依赖私有历史前端 bundle 的兼容性探针；该探针保留为 `test:legacy-compat`。

## 验证

- `npm test`、`npm run verify:all` 通过。
- 真实本地 SenseVoice、增量识别、键盘、原生输入、服务端协议及云生命周期测试通过。
- 隔离 QA 应用中的真实 AX 捕获和剪贴板交付结果为 `verified`。
- macOS arm64 App、SQLite、Koffi、sherpa-onnx 和原生 helper 架构检查通过。

## 安装说明

macOS 包仍使用 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。系统可能显示安全提示；首次安装或更新后可能需要重新授予麦克风、辅助功能与输入监控权限。
