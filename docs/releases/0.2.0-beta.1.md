## 本版变化

包含此前已完成的语音传输、配置、凭据与同步修复；增加 SenseVoice Small INT8 本地推理选项及独立 DeepSeek 官方非思考润色。测试包内置固定校验和的 SenseVoice 模型，首次启动复制到本机模型缓存，已有正确文件不被重写。密钥未打入安装包；本机待导入加密配置由新版启动后处理。

Beta 专用构建命令为 `npm run pack:beta`，保持普通 release 目录中的旧副本不变。Beta 使用有效的本地 ad-hoc 签名，且最低系统版本为 13.0。没有 Developer ID 签名或苹果公证，用户可能需要按系统提示允许打开。

## 验证

- `npm run verify` 通过，包含类型检查、全部基础和联调测试、原生库检查、剪贴板检查、网关 30 项与无 GUI e2e 16 项。
- 源码真实 Electron 测试验证内置模型首启校验复制、保留已有模型、修复损坏 tokens，以及 WAV/Ogg 识别和进程生命周期。
- 最终 DMG 实际只读挂载并校验成功，含 OpenType.app 和 Applications 拖放链接。
- 挂载镜像内应用通过 `codesign --verify --deep --strict`。打包主可执行文件在 Node 模式可启动；未将新版安装或启动到用户的真实数据目录。
- 从挂载镜像内的 ASAR worker 与模型重跑真实识别测试，取消、忙碌保护、空闲退出、重新识别和语言/长录音回退通过。
- 最终包中的主程序、worker、模型出处声明与本次构建一致；ASAR 未发现 API Key 形式的明文凭据。
- PDF 全部 7 页渲染检查通过，文本提取包含所有主要测试编号，交付副本与生成文件一致。

## 测试范围

先选 SenseVoice，关闭 DeepSeek 测原始识别，再开启测整理；安装和记录方法详见指南。超过 30 秒的录音及非五语场景仍依赖本地 Whisper 网关。词典接入、长录音原生分段、正式签名更新、完整前端和多平台尚未完成，本版不代表 TypeLess 完整替代验收。
