# OpenType 0.2.0-beta.16

新增历史页 → **管理录音存储**，处理旧版本或异常退出后失去历史归属的录音。先扫描核对文件名、时间和大小，再试听、找回到历史或移入录音回收站。

只列出应用录音目录中超过 24 小时的 WAV/Ogg/WebM 文件。近期修改/复制、正在写入、有历史归属、已进入历史删除队列的文件，以及未知文件、目录和链接都会保留。确认操作时再次核对文件身份与归属，过期或变化的扫描结果需重新检查。

“找回到历史”只建立本地待识别记录，不自动识别或上传音频；之后可播放、导出、重新识别。找回记录从当前时间开始计算本地保留期，无法确定原录音时长时显示“时长未知”。

移入回收站后仍可找回到历史或仅还原文件，退出重启继续保留；只有再次明确确认“永久删除所选”才删除文件。**移入回收站本身不释放磁盘空间。** 永久删除失败会留在回收站，重新扫描不会擅自重试删除。

新增 23 组真实数据库/文件测试及 IPC 来源校验；完整回归通过。实际生产页面完成试听、找回、取消/确认、回收站重启和按项删除；真实主进程的入口、IPC 和保护计数也验证通过。界面验收使用临时样本和受控文件年龄，重识别响应由夹具模拟，不代表真人语音准确率。

本地模型仍仅 SenseVoice Small，保持自然停顿提前识别和无产品录音时长上限。安装包适用 macOS 13+ / Apple Silicon，ad-hoc 签名，尚未 Apple 公证。整体替代验收继续进行。
