# OpenType 0.2.0-beta.7

默认支持同一快捷键的两种操作：短按开始/停止，长按说话、松手结束。设置中也可选择固定短按或固定长按；首页和录音胶囊提示随状态变化，设置重启后保留。

单独修饰键先等待约 0.3 秒，避免把正常组合键的前半段当成听写。长按时请看到胶囊后再说话；若继续组成普通快捷键，已经开始的临时录音会取消。按键设置、取消、监听重连、锁屏/休眠统一清理按键状态；按钮/托盘启动的录音也可用快捷键结束。处理期间不重叠启动。

继续保留 SenseVoice Small、停顿预识别、无产品录音时长限制和 beta.6 的本机历史/录音删除修复。

完整 `npm run verify:all` 通过，新增 20 组录音控制场景，原生 Swift/Koffi 长按与组合键回归通过；实际界面验证了 F8 录入、录音方式选择和退出重启后的设置。实体键盘、真人麦克风、物理休眠及跨应用粘贴仍需真人复测，详见配套清单。

本批实际 SenseVoice 复测通过：36 秒合成中文音频，关闭整理，在本机 M4 上停止后等待从约 641 ms 降到 133 ms，尾句完整。这是单个 PCM 样本，不包含真人麦克风、系统插字或云端整理耗时。

macOS 13+ / Apple Silicon。ad-hoc 签名，未 Developer ID 签名与 Apple 公证。本次未替换已安装应用或操作真实历史。完整替代目标尚未完成，包括云端删除传播、中文输出偏好和纠词学习等后续项目。
