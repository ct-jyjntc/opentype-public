# OpenType 0.2.0-beta.14

新增“从输入框修改生成纠词建议”，位于设置 → 个性化，默认关闭。开启后，普通听写确认插入成功时，会短暂检测原输入框中本次插入内容的修改；停稳后生成本机待审核词条，确认后才加入词典。无需回历史页重复修改。

检测最多持续一分钟；切换应用或输入框、修改插入范围外内容、开始下一次录音、关闭开关、锁屏、休眠或退出会停止。它会临时读取原输入框核对前后边界，只有本次插入区域的文字交给本机候选提取；不保存整份编辑器内容、不自动修改历史、不上传候选。密码框、受保护上下文、黑名单网页及其父页面不参与。

词典区分“输入框修改”和“历史修改”，提供审核、忽略、查看原始历史和删除已确认词条。新增更严格的拼写差异筛选，减少把整句改写误当词汇；建议仍需人工审核，不能保证所有专名都能检测。SenseVoice 权重不变，已确认词条由启用的 DeepSeek 整理参考。

完整自动化回归通过，新增 12 组输入框纠词/真实数据库场景，录音会话回归增至 23 组。实际跨进程验证通过原生 AppKit 编辑器、Swift/Koffi、生产录音会话和 SQLite；纠错动作由测试夹具模拟。实际前端的审核、忽略、来源和设置/词条重启保留通过，不代表真人打字、语音或所有编辑器均已验收。

仅内置 SenseVoice Small，无产品录音时长上限；一分钟仅是可选纠词检测时间。macOS 13+ / Apple Silicon；ad-hoc 签名，尚未 Apple 公证。
