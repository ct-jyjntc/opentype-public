# OpenType 0.2.0-beta.21

日期：2026-10-09。本轮移除内置系统拼音，产品专注语音输入。SenseVoice Small、自然停顿提前识别、不限总录音时长、听写/翻译/随便问、Skills、历史和语音词典保留。

- 删除拼音页面、候选窗、短语导入导出及同步接口，移除 macOS IMK/Rime 和 Windows TSF/Rime 源码与打包资源。
- 语音输入直接捕获目标输入框，继续校验焦点、选区和输入结果；移除仅供 OpenType 拼音使用的组合文本交接协议。
- 保留旧版个人词库、配置及已有数据库表，不执行数据删除；新版不再创建或使用拼音专用存储。
- 本机此前独立安装的 `OpenType Pinyin.app` 经身份校验和安全退出准备后已移入系统废纸篓。没有强制切换输入法或删除个人词库；这次本机清理并非安装包的自动迁移功能。
- 保留 beta.20 的紧凑界面、可读正文字号、浅深主题和横向/纵向滚动条；语音词典中的常见误识别与读音提示仍可使用。

源码 `2876eb0b4610b6ecf7e567dc6fad09cccd042c3f` 已先推送 `main`，随后生成 macOS arm64 DMG/ZIP。四个原生 helper、OutputAudio、主进程和渲染层已重新编译，类型检查成功；签名结构与 DMG/ZIP 完整性校验通过。包内包含五个语音 helper 与 SenseVoice Small，不包含拼音组件或 Whisper。构建来源见 [BUILD_INFO.json](../../release/testing/0.2.0-beta.21/BUILD_INFO.json)。

独立原生真路径已将专用 AppKit 输入框中的 `🙂` 替换为 `【听写成功】`，正式 `deliverToInput` 返回 `verified`、`clipboard`；改变目标内容后第二次交付被 `injection_target_changed` 拒绝。带旧配置的隔离应用正常启动，五张旧拼音表的行数前后均为 1/0/1/0/0；这是计数保留证据，不是全部旧数据逐字节一致性证明。最终 DMG 应用已确认设置无拼音入口、F8 录入暂停听写且可取消，以及语音词典读音提示编辑保存。包内 SenseVoice 引擎和模型实际输出“明天下午3点开会讨论下个季度的产品路线图。”。详见 [beta.21 测试结果](../testing/OpenType-0.2.0-beta.21-测试结果.md)。

安装包为本地 ad-hoc 签名，未公证，不发布 GitHub Release；保留 beta.20 及更早安装包。Windows 源码已同步删除拼音组件，但本机无 Windows 编译环境，尚未编译或运行。

独立本地 HTTP 验证已确认三条旧拼音同步路由返回 `404 unknown_route`，普通词典创建与列表回读一致，同步状态仍可读取。语音路由对无效请求返回 `400 expected_multipart`，仅证明请求边界，不代表转写通过。原始响应见 [HTTP 记录](../../tmp/qa-beta21/runtime-http-results.json)。没有部署远端服务，旧客户端连接已部署服务的行为不会因本次本地源码修改自动改变。

旧项目生成目录 `native/input-method/build` 经确认后已通过系统废纸篓 API 移至 `~/.Trash/build`，个人数据与旧发布包保留。本轮未独立调用旧拼音 IPC；物理右 Command、真人麦克风与长句自然停顿、录音取消及第三方应用兼容性仍需真人复测。包内引擎转写和专用输入框交付分别取得证据，不能合并声称完整麦克风端到端链路已验。
