# OpenType 0.2.0-beta.12

本版改进日常听写的文字交付。开始录音时保存原应用、窗口、输入框及选区；结束后恢复该位置，再发送一次粘贴并核对输入框内容。输入框原文已改动、窗口关闭或位置无法恢复时，保留识别结果并提示复制，避免覆盖新编辑或误投其他窗口。

交付结果分为三种：内容核对成功；已尝试发送但无法确认，需要核对输入框；尚未发送，可从提示卡或历史复制。后两种不会冒充“已插入”，也不会自动重复粘贴。识别原文和最终文字继续保存在历史中。

实际测试修复了同步原生调用导致 Electron 重入崩溃、网页声明支持辅助功能写入但实际忽略、以及网页选区异步恢复尚未完成就判断失败的问题。密码框、只读框，以及无法读取或恢复选区的控件不建立自动交付目标；这些应用仍可用手动复制结果的方式输入。

完整 `npm run verify:all` 通过，含 11 组交付协调场景、19 组录音会话场景及原生 UTF-16 范围检查。实际隔离界面验证了同应用切窗、双向 Electron/AppKit 跨应用恢复、表情选区替换、原文修改、窗口关闭、应用退出、光标移动、只读与安全框。测试使用合成文字，没有修改真实历史数据；不代表所有第三方富文本编辑器已兼容。

仅内置 SenseVoice Small，保持自然停顿预识别和无产品录音时长上限。macOS 13+ / Apple Silicon；ad-hoc 签名，尚未 Developer ID 签名和 Apple 公证。真人键盘/麦克风、多屏/休眠、真实识别质量、生产服务、其他平台及完整替代目标仍待验收。
