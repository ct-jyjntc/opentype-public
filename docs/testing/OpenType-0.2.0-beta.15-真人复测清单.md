# beta.15 真人复测清单

退出旧版，安装同目录的 `OpenType-0.2.0-beta.15-macOS-arm64.dmg`，在关于页核对版本。系统要求 macOS 13+、Apple Silicon。保留旧版安装包便于回退；不要删除现有用户数据目录。

本版重点是云端历史生命周期。使用专门的测试账户与可丢弃测试记录；服务端必须升级到本版接口。普通本地听写不需要账户或云同步。安装包尚未 Apple 公证。

## 持续体验对比

沿用 [beta.14 输入框纠词清单](OpenType-0.2.0-beta.14-真人复测清单.md)、[beta.13 选区交付清单](OpenType-0.2.0-beta.13-真人复测清单.md) 和 [既有功能清单](OpenType-0.2.0-beta.13-既有功能回归清单.md)。旧版结论不能直接填为本版通过。

用同一麦克风、相同输入框和相同句子分别测试 OpenType、Typeless、Chatterfly，各重复三次，记录全文、漏字/重复/改口、停止到完整插入的三次等待。包括聊天、邮件、列表、中英混说、专业名词、只读选区提问及可编辑选区替换。

失败记录：系统/软件版本、操作顺序、同步开关与保留期、哪台设备、预期/实际文本、云端数量、是否仍能播放本机录音。仅分享合成测试材料，不要附上 API Key 或账户凭据。

## 本轮已验证范围

完整自动化通过，含真实 SQLite 和本地隔离服务的 12 组生命周期测试、4 组迁移/事务测试和 25 组同步测试。实际生产前端通过 CUA 验证确认/取消、7 天到期、响应丢失提示、重启、同一次重试保留新记录；三份合成录音文件逐字节未变。

这里的录音保留证据来自合成文件；语音模型测试使用系统合成语音。真人麦克风、实体键盘、真实多设备、第三方编辑器及生产网络仍需填写上述复测结果。整体替代目标尚未完成。
