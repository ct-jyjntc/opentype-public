## 真人复测清单

建议保留旧版本安装包，在不含重要未保存内容的文本窗口测试。每项记录“通过/失败、实际表现”，异常附版本、页面、操作顺序和截图。

1. **主要入口**：打开首页、历史、词典、Skills、设置。Skills 应在侧栏独立显示，首页“管理 Skills”进入同一页；没有系统拼音入口。
2. **Skills 菜单**：新建一个临时 Skill，编辑、搜索、复制、上移/下移；禁用或到达列表边界的操作不应执行。键盘使用 Tab / Shift+Tab 移动焦点，用 Enter 打开菜单或执行项目，再尝试 Esc；Esc 关闭菜单并回到原按钮。删除先出现确认框，取消应保留项目。
3. **历史草稿与 Esc**：打开一条历史，修改文字但不保存，打开“更多操作”，按一次 Esc。详情应保留，草稿仍在；再次打开菜单应可操作。保存后重新打开核对修改。恢复原文、重新识别及导出录音须可找到；删除仍需确认。
4. **窗口与滚动**：把主窗口缩至允许的最小尺寸，分别选择浅色和深色；检查 Skills 长列表、词典、历史、设置末页及编辑弹窗。滚轮、触控板及拖动滚动条均应可用，最后一条项目的菜单和底部按钮可达。恢复大窗口后排版应正常。
5. **引导与模型**：新环境首次引导能前进与返回；无权限时状态清楚，不要求为了测试清除日常配置。设置中模型应为 SenseVoice Small；打开听写模型页检查滚动、模型状态及 DeepSeek 配置入口。
6. **快捷键录入**：点击快捷键设置按钮，按物理右 Command，再试其他键。录入期间只更新待保存按键，不应直接开始听写；Esc 取消录入，保存后在普通输入框试用。记录短按切换与按住说话两种方式。
7. **三种胶囊**：分别启动听写、翻译、随便问，核对白/蓝/绿模式色、停止、取消及处理状态。胶囊不再显示计时或中间文字。翻译与随便问需要用户已配置的 DeepSeek；未配置时应显示可理解的失败原因。
8. **异常提示**：在方便且可恢复的测试环境中尝试断开正在使用的外接麦克风，核对提前停止提示及此前内容；不要依赖显示“已完成”判断全文录完。若遇音量控制或输入失败，检查胶囊提示/悬停说明及可复制结果，记录完整原因。没有相应设备时记“未测”。
9. **回答卡片**：生成短回答和长回答，滚到最后一段并复制，观察高度是否稳定；选中文字后使用摘要/改写等操作。只有显式点击“替换选中文字”才应替换，取消处理后不应稍后突然改写。云端功能未配置时记“未测”。
10. **真实语音与长录音**：关闭可选 DeepSeek 整理，口述一段含时间、专有名称的中文；连续说超过两分钟，包含几次自然停顿，末句说“以上是全部内容”。不应按固定时长停止，末句和全文应保留。记录停止到输出的耗时、漏字、重复和断句；首页试听结果到历史核对，不应写入外部应用。
11. **取消与目标变化**：在录音中和结束处理时分别按 Esc，确认取消后不会晚到插入；录音期间切换目标或修改选区，再结束，检查防误写提示和内容恢复入口。仅在临时文本中操作。

记录格式：`步骤编号｜通过/失败/未测｜实际文字或界面表现｜等待秒数｜应用名称｜备注`。
