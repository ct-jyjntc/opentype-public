# beta.7 快捷键真人复测

适用 macOS 13+ / Apple Silicon。退出旧版后安装 beta.7，确认关于页版本；测试时先退出其他使用相同全局快捷键的语音应用。测试包使用 ad-hoc 签名，尚未 Apple 公证。

在设置 → 录音方式中，默认选择“短按或长按”。单独修饰键（右 Command、Fn 等）会先等待约 0.3 秒判断是否组成其他快捷键；长按时看到录音胶囊后再说话。这个时间是按键判断时间，不是录音时长限制。

口述测试句：**这是一条快捷键测试，明天下午三点开会。** 建议先关闭文字整理，在空白文本编辑器中测试。

## 自动化证据与真人验收边界

本批实际 SenseVoice 测试使用 36 秒中文合成语音按实际时长送入 PCM，在 M4 上停止到文字返回约 133 ms，整段识别基线约 641 ms。该单次结果不包含麦克风采集、系统插入或云端整理，不代表真人准确率或所有机器的速度。

自动化已经覆盖状态机、原生 Swift/Koffi 事件、录音协调、取消、锁屏/恢复事件路由和设置接口。UI 工具能在录入器中录入 F8，但未触发全局监听，因此实体键盘与物理休眠必须由真人确认。当前测试环境的 Chromium 文件麦克风读入被沙箱拒绝，本批 UI 音频测试只验证了静音错误与收尾，不能当作真人识别验收。
