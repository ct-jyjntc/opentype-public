# beta.16 真人复测清单

安装 `OpenType-0.2.0-beta.16-macOS-arm64.dmg`，在关于页核对版本。适用于 macOS 13+ / Apple Silicon，尚未 Apple 公证。保留旧安装包，不要删除现有用户数据目录。

本轮重点是历史页的“管理录音存储”。扫描本身不会把普通候选移走。清理先进入应用自己的录音回收站，回收站不会自动清空；永久删除必须再次确认。此前已确认但未完成的移动/还原操作会在扫描时继续核对，永久删除失败则需要重新确认。

## 扫描与找回

先打开“历史记录 → 管理录音存储”。只选择自己明确可用于测试的录音，不要为制造孤立文件而删除真实数据库或移动正常录音。没有候选是正常结果，保留为“未测”即可。

| 操作 | 预期 | 结果 |
| --- | --- | --- |
| 第一次扫描，记录候选/保护计数 | 显示文件名、时间、大小；默认没有勾选文件 | □通过 □失败 □未测 |
| 核对正常历史、刚产生或刚复制的录音 | 不进入候选；近期文件至少保护 24 小时 | □通过 □失败 □未测 |
| 选择“试听” | 正常文件可播放/暂停；损坏文件可能无法解码，但不会自动删除 | □通过 □失败 □未测 |
| 试听大于 32 MB 的候选 | 提示先找回历史后播放或导出；仍可找回，不限制录音长度 | □通过 □失败 □未测 |
| 选择一份测试录音并“找回到历史” | 候选减少，历史新增“已找回录音 · 可识别”；不会立即发起识别 | □通过 □失败 □未测 |
| 找回后打开详情 | 原始录音可播放/导出；无法推断时长时显示“时长未知” | □通过 □失败 □未测 |
| 对找回的测试录音点击“重新识别” | 按当前模型和整理设置识别，成功后出现文字 | □通过 □失败 □未测 |
| 退出重启 | 找回的历史记录、原音频和已识别文字保留 | □通过 □失败 □未测 |

找回录音不会还原已丢失的原文字、输入应用、语言或其他旧元数据；它保存原录音供重新识别。重新识别后，文本整理和历史云同步仍遵循已有设置。

| 操作 | 预期 | 结果 |

| 再次确认移入 | 候选减少，回收站增加；提示尚未释放空间 | □通过 □失败 □未测 |
| 退出重启后查看回收站 | 原文件仍在，试听可用 | □通过 □失败 □未测 |
| 回收站中选择“找回到历史” | 回收站减少，历史出现录音；字节内容与导出样本一致 | □通过 □失败 □未测 |
| 选择“仅还原文件” | 文件回到原位置；不会覆盖同名文件，也不会自动创建历史；近期保护重新生效 | □通过 □失败 □未测 |
| 对可丢弃样本点击“永久删除所选”后取消 | 文件仍在回收站 | □通过 □失败 □未测 |
| 对同一可丢弃样本确认永久删除 | 只删除所选项；正常历史、近期文件和未选项不变 | □通过 □失败 □未测 |
| 使用 Tab / Shift+Tab / Esc 操作确认框 | 控件可访问，Esc 只关闭当前确认；不会误触确认 | □通过 □失败 □未测 |

永久删除无法通过应用恢复；不会宣称擦除 SSD、系统快照、备份或导出副本。文件大小与系统即时可用空间变化可能因系统缓存、快照而不同。
