## 快捷键录入

1. 点击“设置 → 语音输入”右侧快捷键按钮。
2. 不输入键名，直接按下并松开右 Command。候选应显示 `RightCommand`，不出现听写胶囊、不开始录音。
3. 按 F8，候选应替换为 `F8`。再按 Ctrl+1，候选应替换为 `Control+1` 或带左右标记的等价组合，不能累积为 `F8+1`。
4. 按普通字母 A，候选应显示 `A`。保存时应提示裸字母不适合作为全局快捷键，不应静默无反应。
5. 再按右 Command 并保存，设置页显示新键名。关闭设置，在空白文本编辑文档中按右 Command，应该正常开始录音，再按一次结束。
6. 重新打开录入，按其他键后取消，旧设置应保留；Esc 也能取消。
7. 录入过程中切到其他窗口，再返回。应显示录入已暂停；点击录入区域后可以重新录入。关闭录入窗口后，正常听写快捷键应恢复。
8. 测试 Fn、Fn+Space、Fn+Shift；单独右 Command 和 Fn 应使用实体键盘确认。
