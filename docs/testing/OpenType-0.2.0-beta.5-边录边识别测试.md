# beta.5 边录边识别真人测试

先退出旧版，再把 DMG 中的 OpenType 拖入“应用程序”替换。确认关于页显示 `0.2.0-beta.5`，本地模型显示 SenseVoice Small 已就绪。测试包是 ad-hoc 签名，未完成 Apple 公证；现有麦克风、输入监控及辅助功能权限仍需有效。

## 测试准备

1. 打开一个空白文本编辑文档，光标放在输入区。
2. 第一轮关闭 DeepSeek 整理，单独观察本地识别速度；第二轮按需开启整理。
3. 记录 Mac 型号、系统版本、麦克风名称、是否使用蓝牙、是否有明显风扇声或背景讲话。
4. 用同一段文字比较 beta.4 与 beta.5。建议用手机计时或录屏，记录从按下停止快捷键到文字完整出现的时间，每项重复三次。

## 核心场景

| 场景 | 操作 | 预期 | 结果 |
|---|---|---|---|
| 自然停顿 | 说 1–2 分钟，每一两句停顿约 1 秒 | 录音持续进行，不提前往目标窗口插字；停止后完整输出，顺序正确 | □通过 □失败 |
| 立即结束 | 最后说“最后一句是明天下午三点开会”，说完立刻停止 | 尾句保留，不要求额外等待一秒再停止 | □通过 □失败 |
| 短停顿 | 在词组中间停顿约 0.2–0.3 秒，再继续说 | 没有明显丢词或重复；录音不自动结束 | □通过 □失败 |
| 连续讲话 | 不刻意停顿，连续说 40–60 秒 | 能完成整段转写，约 25 秒附近无明显截断；停止后可能仍需处理剩余任务 | □通过 □失败 |
| 真实重复 | 说“确认，确认。明天开会，明天开会。” | 关闭整理时不能因为文本相同就去掉真实重复 | □通过 □失败 |
| 很短一句 | 说“好”或“收到”后立即停止 | 不因时长短而直接丢弃 | □通过 □失败 |
| 低声与噪声 | 分别轻声说话、在风扇声下说同一段话 | 检查漏词和错误断句；停顿不明显时允许处理较晚 | □通过 □失败 |
| 较长停顿 | 说两句，静默 10 秒，再接着说 | 不自动停止；已说和后续内容都保留 | □通过 □失败 |
| 取消后重录 | 说几句并停顿，按 Esc；马上录一条不同内容 | 取消的文字不会迟到插入，也不会混入新录音 | □通过 □失败 |
| 停止处理中取消 | 结束后若仍在处理，按 Esc，再重新录音 | 不输出被取消的旧结果，新录音可用 | □通过 □失败 |
| 10 分钟录音 | 正常讲话，可穿插停顿，主动结束 | 不在 9 分钟停止，全文和历史录音完整 | □通过 □失败 |
| 历史与重试 | 打开本次历史，播放、导出和重新识别 | 保存的是完整录音；重新识别能从原始音频恢复全文 | □通过 □失败 |

## 开启文字整理后

- 跨停顿自我更正：“会议定在周三。”停顿一秒，再说“不对，改成周五下午三点。”结果应保留最终意思。
- 录音过程中目标窗口仍不插入中间结果；结束后才整理并插入全文。
- 翻译和语音指令仍针对完整内容执行，不能逐段翻译或分别执行指令。
- 若网络不可用，普通听写应保留识别原文；翻译/指令应明确失败，不冒充完成。

## 已知验证边界

本机测试使用 36 秒中文合成语音，以实际时长送入录音会话：停止前完成 5 段，结束后补齐第 6 段；关闭整理时，停止到文字返回约 0.67 秒降至 0.14 秒。该结果不含实体麦克风采集、系统粘贴及云端整理耗时，也不代表所有 Mac 的速度或真人识别准确率。较慢机器若有识别任务积压，停止后仍需等待剩余任务完成。
