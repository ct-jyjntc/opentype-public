# OpenType beta.6 真人复测清单

安装前退出正在运行的 OpenType；测试 OpenType 时先退出 Typeless，并避免触发 Chatterfly 的同名快捷键。将 DMG 中的应用拖入“应用程序”，关于页应显示 `0.2.0-beta.6`。适用 macOS 13+ / Apple Silicon；测试包未 Apple 公证。

请只删除本次专门录制的测试记录，不要使用重要历史验证删除。测试短句：**这是一条可以删除的测试记录，今天检查快捷键和本地录音。**
