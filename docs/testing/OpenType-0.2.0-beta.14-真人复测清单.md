# beta.14 真人复测清单

退出旧版，安装同目录的 `OpenType-0.2.0-beta.14-macOS-arm64.dmg`，核对关于页版本。适用 macOS 13+ / Apple Silicon，测试包为 ad-hoc 签名、尚未 Apple 公证。先退出使用相同快捷键的其他语音工具，用空白文档、合成句子或未发送的测试草稿进行。

## 输入框纠词

在设置 → 个性化开启“从输入框修改生成纠词建议”。它默认关闭，与历史修改建议是两个独立开关。普通听写需要开启自动插入并成功交付；首页“试试听写”、失败后的手动复制、翻译和随便问不启动检测。

选择一个您确实会说错或模型会识别错的名称，例如 OpenType、SenseVoice、同事的虚构姓名。先关闭文字整理，录制含该名称的一句普通听写。若识别正确，可换一个难词；无需为了凑测试把正确文字改错，无误识别时该项标“未测”。

检测期间在原输入框中只改正刚插入句子里的错字，停约两秒后再打开词典查看。离开输入框会终止检测，因此先完成纠错再切到 OpenType。已确认词条在开启 DeepSeek 整理后才作为参考，不会修改 SenseVoice 模型权重。

| 切应用/输入框 | 听写后切到另一个框或应用，再修改文字 | 原检测结束，不采集新目标的输入；返回原框也不自动恢复旧检测 | □通过 □失败 □未测 |
| 新录音 | 原句刚插入后再次开始听写 | 旧检测停止，仅新一次成功插入有自己的检测范围 | □通过 □失败 □未测 |

| 开关独立 | 关闭历史修改建议，开启输入框检测，然后原地改错 | 输入框检测仍可用；反过来也独立生效 | □通过 □失败 □未测 |
| 重启保留 | 保存开关、确认和忽略各一条建议，正常退出重启 | 开关、词条和忽略状态保留；不会恢复旧输入框检测 | □通过 □失败 □未测 |
| 编辑/删除来源 | 在历史中编辑或删除专用于本次测试的来源记录 | 旧待审核候选失效；已确认词条独立保留，可手动删除 | □通过 □失败 □未测 |
| 非词汇编辑 | 仅改标点、加空格或追加一句话 | 不把纯格式变化或纯新增内容变成词条 | □通过 □失败 □未测 |
| 大幅改写 | 把一句话改成另一段意思不同的表达 | 不应出现不合适的词条；若出现请记录候选并忽略 | □通过 □失败 □未测 |
| 隐私场景 | 仅在自建密码测试框或已有黑名单测试网页里使用合成文字 | 不启用检测，不产生来自受保护文字的建议 | □通过 □失败 □未测 |
| 锁屏/休眠 | 在可丢弃的测试句插入后锁屏或休眠，再恢复 | 旧检测不恢复；下一次听写正常 | □通过 □失败 □未测 |

检测只对可靠提供原文、焦点和选区的输入框工作。超过十万 UTF-16 字符的插入内容、超过一百万字符的原输入框跳过自动纠词分析；**这些边界不限制录音或听写长度**。不支持的编辑器请记下名称和版本，不要把“没有建议”直接视为录音失败。

## 既有功能回归和参考产品对照

先测快捷键设置能录入右 Command/F8，且不会触发听写；再做离线普通听写、2 分钟和 10 分钟自然停顿录音，检查全文顺序、尾句和停止后等待。随便问应先显示卡片，明确点击才替换；只读文章只能复制回答，原文变动会阻止替换。

完整步骤见同目录 [上一版选区与交付回归](OpenType-0.2.0-beta.13-真人复测清单.md) 和 [既有功能回归清单](OpenType-0.2.0-beta.13-既有功能回归清单.md)。其中旧版测试结论是历史证据，在 beta.14 上执行后才能填写通过。

用相同麦克风、输入框和语句分别测试 OpenType、Typeless、Chatterfly，每项重复三次。记录是否开启整理、错词/漏字/重复、停止到完整插入的三次等待，以及改正错词后再次听写的结果。不要只取最快一次或用模拟响应代表真实纠词效果。

失败反馈：应用和系统版本、输入框类型、开关状态、原听写句、修改后的句子、是否切换窗口、修改时间距插入多久、候选实际内容。只分享合成测试资料，不需要私人录音或 API Key。

## 当前验证边界

自动化、真实数据库、原生桥跨进程和实际前端审核/重启检查通过。成功的跨进程候选检测使用模拟语音和夹具内文本编辑；CUA 定向打字测试遇到前台被恢复到调用应用，触发停止保护，未计为真人打字通过。实体键盘/麦克风、真实模型效果、第三方编辑器/浏览器/办公软件、多屏及物理休眠仍待复测。
