# OpenType 0.2.x 识别语料边界（合成门禁 / 真人复测）

对齐：发布门禁 E/F 节、N1 冷启动、N3 真人主路径。负责人：算法与数据工程师。

## 1. 总原则

| 用途 | 允许 | 禁止 |
|------|------|------|
| 合成门禁（能不能发） | 固定合成朗读稿 + TTS/系统朗读生成的音频，或脚本注入的已有 WAV/Ogg Opus | 真实用户录音、个人词库、密钥、账户数据进仓或进报告 |
| 真人复测（正式对外） | 测试者当场口述下列**提示句**（不录音入库） | 把麦克风录音文件、用户历史、词典同步内容提交到 Git / PR / 公开报告 |

报告只记：通过/失败、现象、版本号、识别方式（云端/本地）、是否丢段；**不附音频、不附识别原文中的隐私字段**。

## 2. 合成门禁语料（固定三档，云端 + 本地各跑）

短句、长句、含停顿多段各一档；中文为主，本地另抽检英/日各一句（可选）。

**S1 短句**

> 今天天气不错，我们开会讨论一下产品计划。

**S2 长句**

> 请把会议纪要发给产品负责人和技术负责人，并说明云端听写需要自行填写密钥，本地模型下载完成并通过校验后才能切换。

**S3 含停顿多段**（朗读时在「。」处停顿约 1–2 秒）

> 第一段，开始录音。  
> 第二段，自然停顿后继续说。  
> 第三段，停止后应合并为完整全文。

**判定（硬）**：主路径可完成 + 合并全文可读 + 无静默丢段 / 重复合并 / 空白。字错率仅趋势参考，不挡发。

## 3. 真人复测口述提示（不入库）

测试者照读或近义复述即可；**不要**把录音文件提交仓库。

1. 短听写写入备忘录/文本框：`打开备忘录，写下今天的待办。`
2. 含停顿：两句之间停 1–2 秒，确认分段识别后合并。
3. 跨应用：从浏览器地址栏切到备忘录再写入，确认目标变化可恢复。
4. 冷启动无 Key：主 CTA 启用本地后再说一句；取消路径确认「识别方式未更改」。

语种抽检（本地 INT8，任选）：广东话短句 / English short sentence / 日本語の短い文。

## 4. 禁区清单（验收直接判否）

1. PR、issue、`docs/` 中出现真实 SiliconFlow / DeepSeek Key、JWT、用户邮箱验证码。
2. 提交 `.wav` / `.ogg` / `.webm` 等真人麦克风录音，或未脱敏的听写历史导出。
3. 个人词库 / 同步库 dump 进仓。
4. 用开放域 WER 刷分替代「可完成 + 合并可读 + 无静默丢段」。
5. 云端缺 Key / 失败时自动切本地（违反 N1）。
