# OpenType 0.2.0-beta.2 可编辑前端测试

适用：macOS 13+、Apple Silicon。此版本内置 SenseVoice，采用完整源码构建的新界面。尚未 Developer ID 签名与公证。先退出旧版，再把 DMG 内的 OpenType 拖到“应用程序”替换；无需删除原有用户数据目录。

每项记录：通过 / 失败、实际现象、发生时间。测试失败时保留历史录音，方便复现。

| 编号 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 01 | 启动应用，未登录进入主界面 | 可查看首页、历史和词典；本地功能不要求登录 | |
| 02 | 首次引导授权麦克风及辅助功能 | 系统显示实际权限状态；返回应用后能继续 | |
| 03 | 设置 → 听写模型，选择 SenseVoice；先关闭 DeepSeek | 模型显示已就绪，保存成功 | |
| 04 | 首页“试试听写”，说“明天下午三点开会，讨论产品路线图”，点“结束测试” | 历史出现文字；此测试不会向其他应用插入 | |
| 05 | 在备忘录输入框中按一次 Fn，说话，再按一次 Fn | 出现录音浮窗；结束后文字插入原输入框 | |
| 06 | 按 Fn 开始录音，按 Esc 取消；立即再录一次 | 第一次无迟到插入，第二次正常结束 | |
| 07 | 分别按 Fn+Shift 与 Fn+Space | 分别进入翻译和随便问；不会提前以普通听写开始 | |
| 08 | 历史中打开录音，播放、暂停、拖动进度 | 可播放已保存的声音；时间前进 | |
| 09 | 详情中查看识别原文，修改整理文字并保存；关闭重开 | 原文仍在，修改后文字被保留 | |
| 10 | 详情点击“重新识别” | 成功后刷新文字；失败时原记录与录音仍在 | |
| 11 | 搜索历史中独特的词，切换听写/翻译筛选 | 结果与搜索及模式匹配；清空后恢复 | |
| 12 | 添加词汇 OpenType、提示 open type；搜索、修改、重启 | 词汇持续保留；重复添加有明确提示 | |
| 13 | 导入 CSV：第一行 term,hint；下一行 TypeScript,type script | 两列分别进入词汇与提示，不把逗号拼进词汇 | |
| 14 | 修改语音输入快捷键，保存并重启 | 页面显示新快捷键，物理按键能够开始和停止 | |
| 15 | 设置切换明亮/黑暗/跟随系统 | 主界面即时改变；重启后保留选择 | |
| 16 | 关闭主窗口，在其他应用继续用快捷键听写 | 常驻录音浮窗工作，重新打开能看到历史 | |
| 17 | 配置 DeepSeek 后说“明天，不，后天下午三点开会” | 去掉明确改口；日期和时间含义不改变 | |
| 18 | 启用个性化并填写“列举事项分行”，说出三个事项 | 整理参考偏好；不会凭空增加事项 | |
| 19 | 选中文字，Fn+Space 说“把这段话改得简洁一些” | 对选中内容进行改写；无选中文字提问时显示回答卡片 | |
| 20 | 有已配置的 Whisper 网关时录制超过 30 秒 | 顺利回退并完成；无网关时应明确报错并保留录音 | |
