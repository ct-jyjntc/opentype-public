# OpenType 0.2.x 发布门禁（能不能发）

对齐来源：产品 / 后端与安全 / 算法与数据 / 前端工程与质量 / 技术负责人五份验收切面（团队群对齐，无冲突）。

合成路径通过下列硬门禁即可判「可发」。真人麦克风与跨应用写入归复测清单，不挡合成门禁，但正式对外前须补真人复测记录。

## A. 构建与仓检（硬门禁）

1. `npm run typecheck`、`npm run build`（含 main / preload / renderer）通过。
2. `npm run pack:beta` 产物完整：安装包 + 更新元数据 + SHA 校验文件。
3. 无真实凭据、用户数据、录音、密钥进仓；`.env.example` 无真值。

## B. 听写主路径（合成可验，硬门禁）

4. 快捷键开始/结束（或按住说话）→ 录音 → 识别 → 分段合并 → 可写入当前输入框；听写本身免登录。
5. 录音中 / 分段识别中 / 合并完成三态可区分；停止后补齐尾段，全文合并可读，无静默丢段 / 重复合并 / 空白。
6. 插入前校验目标；目标变化保留可恢复内容，有明确恢复入口，不静默丢字。

## C. 云端默认 / 本地可选（硬门禁）

7. 新装默认云端 SenseVoiceSmall（SiliconFlow `FunAudioLLM/SenseVoiceSmall`），须引导填 SiliconFlow Key；缺 Key / 网络失败不自动回退本地或其他服务。
8. 本地 SenseVoice Small INT8 为显式「下载并启用」：进度 / 成功 / 取消 / 失败可读；SHA-256 通过才切，取消 / 失败保留原方式。
9. 界面可分清「音频是否出机」「整理是否上云」；本地音频不出机；云端按片段上传固定接口；整理仅文字上云；SiliconFlow / DeepSeek 两把 Key 分存，回读只显示已保存 / 未保存，不回显明文。

## D. 账户 / 同步 / 安全（硬门禁）

10. 只打 `https://api.opentype.top`，无自定义服务器入口；历史 / 词典同步分开关且默认关；未开同步 → 上传 403；录音不同步。
11. 注册 / 登录必过 Turnstile；旧 token 在退出 / 删号 / refresh 后 → 401；邮件验证码未开放时界面明示且服务端不假装可用。
12. 更新走固定 HTTPS + SHA-512（及清单校验）；失败可恢复并说明原因；CDN 对 API 须 `no-store` / 非 HIT。

## E. 识别质量口径（合成）

13. 用固定合成语料（短句 / 长句 / 含停顿多段）分别跑云端与本地。
14. 发布门禁看「主路径可完成 + 合并可读 + 无静默丢段」；字错率仅作趋势参考，不以开放域 WER 刷分为准。
15. 本地 INT8：中 / 粤 / 英 / 日 / 韩；WAV 与 Ogg Opus；模型独立进程，崩溃不得拖垮主进程。
16. 模型优先复用安装包内有效文件；缺失时从官网固定版本地址下载并校验 SHA-256；权重不进 Git。

## F. 明确非目标 / 复测边界

17. 不以拼音键盘、候选窗、Rime / IMK / TSF、本地 Whisper 为缺口。
18. 真人麦克风与跨应用写入归 `docs/testing/` 复测清单。
19. 真实用户录音、个人词库、密钥不得进仓或进评测报告。

## 判发规则

- **可发（合成门禁）**：A–E 硬门禁全部通过，且无 F 所列禁区违规。
- **正式对外**：在可发基础上，补齐当期真人复测记录（麦克风 + 跨应用写入）。
- 口径冲突或门槛变更：回团队群 @质量保障与发布工程师，并同步相关切面负责人。
