# beta.13 真人复测清单

安装本目录的 `OpenType-0.2.0-beta.13-macOS-arm64.dmg`，退出旧版本后启动，核对关于页版本。适用 macOS 13+ / Apple Silicon。包使用 ad-hoc 签名，尚未 Apple 公证；没有覆盖你现有的安装与历史数据。

先退出使用相同快捷键的其他语音工具。“随便问”默认 Fn+Space，需要在“听写模型”中配置并启用 DeepSeek。普通离线听写仍可独立使用；未配置整理服务时，不会冒充已经回答。请使用下列合成句或可丢弃草稿测试。

## 回答先审阅，再决定替换

在一个可编辑测试框中输入：**明天下午三点开会，请提前准备好相关资料。**

|---|---|---|---|

| 明确替换 | 核对回答未丢失事实后点击替换 | 返回原输入位置，只替换最初选中的文字，提示已替换 | □通过 □失败 □未测 |
| 解释原句 | 选中测试句，说“解释这句话表达了哪些要求” | 解释出现在卡片，原句不自动变成解释内容 | □通过 □失败 □未测 |

## 只读选区和隐私

用公开网页文章或本地自建测试页测试；不要用私人会话、真实密码或敏感文档。测试“只读”是指网页正文、不可编辑的文字等，不是暂时还未点击的输入框。

| 场景 | 操作 | 预期 | 结果 |
|---|---|---|---|
| 网页正文 | 鼠标选中公开文章的一句话，随便问“用简单的话解释这句话” | 回答参考该句；卡片只提供复制，不提供替换网页原文 | □通过 □失败 □未测 |
| 只读输入框 | 在自建 readonly 文本框中选中测试句，再提问 | 可以参考选区作答，不提供替换按钮 | □通过 □失败 □未测 |
| 仅用选区 | 在长篇公开文章中只选一小句，问“复述选中的句子” | 核对回答对应选中内容，没有误用另一段或另一标签页的选区 | □通过 □失败 □未测 |
| 普通听写 | 在同一只读页面使用普通听写快捷键 | 不自动把正文当作问题素材，听写结果保留供复制 | □通过 □失败 □未测 |
| 无选区提问 | 取消选中，再问一个独立问题 | 正常显示回答，没有替换按钮 | □通过 □失败 □未测 |
| 密码框 | 仅在自己创建的密码测试框放入合成文本，选中后提问 | 不读取密码，不提供替换；回答卡片说明输入环境文字未用于回答 | □通过 □失败 □未测 |
| 受保护应用/网页 | 在已有隐私规则限制的测试页面或应用中选择合成文字后提问 | 不附加受保护的文字，卡片说明未使用输入环境内容 | □通过 □失败 □未测 |
| 嵌入式编辑器 | 有测试条件时，在黑名单父页面的 iframe 内选中合成文字 | 父页面的限制仍生效，不因 iframe 来源不同绕过 | □通过 □失败 □未测 |

受保护的选区不会因为提问而自动解除隐私限制。如果卡片提示未使用输入环境文字，回答不能视作已经理解了那段选区。无对应测试站点或配置时请标记“未测”。

完整的切窗、剪贴板、历史、纠词与网络检查见同目录“既有功能回归清单.md”。与 Typeless、Chatterfly 对照时使用同一句、同一输入框和麦克风，每项重复三次；记录回答质量、替换范围和停止后等待时间。

失败反馈：软件版本、系统与目标应用版本、选中的原句、语音指令、回答、是否点击替换、期间是否切窗/编辑/删除，以及实际插入位置。只需分享合成测试内容，不需要发送私人录音或 API Key。

## 当前验证边界

完整自动化回归已通过，新增回答卡片和选区隐私测试使用真实临时 SQLite；实际界面测试走真实 Swift/Koffi 选区读取和插入、生产录音会话与卡片控制器、真实卡片 renderer，但语音识别和回答使用合成固定结果。已覆盖只读框、网页正文、普通/富文本框、原文变化保护和跨来源 iframe 父页面黑名单。

这些结果不代表真人麦克风、模型解释质量、所有浏览器/PDF/办公软件/终端、多屏和实体键盘全部通过。需要以上真人步骤继续验收，不能把“未测”计为通过。
