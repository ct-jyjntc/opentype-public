## 安装与准备

1. 退出旧 OpenType，打开本目录 DMG，将 OpenType 拖到“应用程序”并替换旧版。已有历史与配置会保留。
2. 打开 OpenType，在“关于”确认 `0.2.0-beta.3`。
3. 在“设置 → 快捷键”查看状态。若提示输入监控权限，点击入口，在“隐私与安全性 → 输入监控”启用 OpenType。列表没有它时，点 `+` 添加 `/Applications/OpenType.app`。若 macOS 要求退出并重新打开，按系统提示操作。
4. 回到 OpenType，点击“重新连接”，应显示“全局快捷键监听已就绪”。麦克风用于录音，辅助功能用于插入文字，也需要分别授权。
5. 优先使用本地 SenseVoice。首次只测试听写；翻译和随便问的文字处理还需要相应模型配置。打开文本编辑，新建一份空白文档，避免往重要内容中测试。

“已就绪”说明监听已启用；是否真正收到物理键，以以下测试结果为准。
