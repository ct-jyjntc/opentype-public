# 短按 / 长按录音控制与验证

版本：0.2.0-beta.7。日期：2026-10-08。

## 行为变化

同一快捷键可短按切换或长按松手结束，用户也可选择固定 toggle/hold。识别语言、SenseVoice、录音分段策略和文字整理保持原方案。

单独修饰键及纯修饰键组合等待 300 ms，允许更完整的组合键优先。短按在松开时触发；自动或长按模式在持续按住时触发。F8 等普通主键的合法绑定可按下立即开始，松开时依持续时间判断是保持还是结束。已开始的修饰键长按若继续组成其他键，会取消临时录音，避免意外文字插入。

录音控制统一处理键盘、UI/托盘、正在处理、取消和失败。开始请求被拒绝时不会留下假的“正在录音”按键状态。设置录音方式和快捷键时要求当前录音已结束；普通偏好修改不重置录音状态。监听重连取消旧录音与旧按键。锁屏与休眠分别记状态，只有恢复且解锁后才重新连接监听，防止仍锁屏时恢复录音快捷键。

设置界面新增录音方式选择；首页提示来自持久偏好，胶囊提示来自实际长按/保持状态。

## 证据与测试范围

- `npm run verify:all` 最终退出码 0。包含客户端、网关、服务端、原生输入与剪贴板等既有检查。
- 新增 `test:recording-controls` 20 组场景：短按/长按、左右修饰键、Cmd+C 前缀、长按后组合键、Fn 组合顺序、固定模式、重复/防抖、取消、录入隔离、开始拒绝、实际 CaptureSession 完成与单次插入、按钮启动、处理中拒绝、失败收尾、禁用、锁屏/休眠路由。
- 扩展原生 Electron 测试：真实 Swift 模块测试入口 → Koffi → 延后派发 JavaScript → 长按计时与松开结束；Cmd+C 不触发；CGEventTap 两次停用后恢复、8,300 次启停仍通过。测试入口直接投递事件，不等于人手按物理键。
- 桌面设置接口验证 auto/hold/toggle 保存与读取、非法值拒绝、录音中拒绝改绑定/方式，修改普通风格不重载快捷键。
- CUA 实际界面：F8 可被录入器识别并保存；长按模式可选择；退出再启动后，首页仍显示 F8 与“按住说话，松开结束”。使用隔离临时配置，无真实用户设置改动。
- 实际 SenseVoice + CaptureSession 复测通过：Apple M4 / 16 GB，关闭文字整理，36.04 秒中文合成语音按实际时长送入 PCM；停止前完成 5 段，停止后完成尾段，共 6 段，全文及尾句保留。停止至文字返回为 133.3 ms；同音频整段识别基线为 640.7 ms，本次减少 79.2%。这是一个合成样本，不包含麦克风采集、跨应用插入或云端整理耗时，不能视为真人识别率或延迟分布。
- 构建打包、严格递归 codesign 与 DMG 校验通过；ASAR 的主进程、主页面和胶囊 bundle 与本次构建文件一致。

完整日志：`tmp/recording-controls/verify-all.log`、`package.log`、`dmg-verify.log`；设置截图：`tmp/recording-controls/settings.png`。

本批实际推理日志：`tmp/recording-controls/live-asr-host.log`；原始测量：`tmp/recording-controls/live-asr-benchmark.json`。此为 beta.7 新复测，未复用 beta.5 的数值。

首次完整验证中新增原生长按测试未收到开始事件：测试在录入器关闭的同一毫秒立即发送下一次按键，命中了既有迟到事件过滤。保留该保护，为测试的新物理手势提供较晚时间戳后完整复验通过。首次失败日志保留为 `verify-first-attempt.log`，没有通过删除断言或放宽产品事件过滤来通过测试。

## 尚未取得的证据

- 锁屏/休眠通过真实代码的事件路由测试，未让用户电脑实际休眠；真人麦克风、蓝牙设备、多屏和跨应用最终插字仍未完成。
