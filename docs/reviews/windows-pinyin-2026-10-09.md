# Windows 拼音组件：系统接入与语音交接

当前目标仅覆盖 Windows 和 macOS。本批补入独立引擎、TSF 组字与候选窗、安装注册、桌面设置和语音交接的源码。功能入口已接线，尚无运行或安装结果，不能据此宣称实际兼容率或选词效果等同参考产品。

遵照用户要求，本批没有运行编译、测试、类型检查、GUI 验收、系统注册或打包。只读取官方 SDK 的发布元数据、归档目录和头文件，将依赖归档保存到开发缓存用于锁定来源；没有执行归档内的工具。没有改动真实用户配置或已交付的 beta.17 安装包。

## 已写入的源码

- `OpenTypePinyinHost.exe` 作为独立进程持有 Rime，引擎不加载到每个目标应用。一个 Windows 用户由同一互斥锁保护学习数据库，避免多个输入组件并发写入。
- 复用 macOS 的公开基础词库、schema 和表情映射。保留全拼/简拼/整句候选、5/7/9 候选数、八组模糊音、中文标点/成对引号、表情和学习开关的后端配置。
- 从独立的 `dev.opentype.inputmethod/settings.json` 读取设置投影，不访问桌面数据库、账号凭据或语音历史。Windows 编译数据和学习文件位于独立 `rime-windows` 子目录。
- 本地与不同账号词库使用不同的个人学习数据库名称。清除学习要求携带当前词库身份且没有正在组字的会话；关闭学习通过 Rime 的个人词库开关控制。
- 设置变化等待现有组字结束后重建。重建期间不开放新的组字会话；会话结束后复用客户端身份并重新创建 Rime 会话。持续的同一配置错误不循环重建，修改设置或明确重试后再次处理。
- 客户端身份绑定实际进程 ID 和进程创建时间；进程退出后清理会话，PID 复用不会继承旧会话。正在组字的会话没有基于说话时间或录音时长的超时限制。
- 每次操作使用顺序号与结果缓存，重复的相同请求返回已产生结果，不重复处理按键。返回已提交文字、中间组字、UTF-16 光标位置、候选和翻页状态；TSF 编辑会话将组字和结果写入原文本范围。
- 本地命名管道按当前用户和 Windows 会话限定，拒绝远程连接。服务端核对实际客户端身份；客户端核对服务端执行路径。请求和响应有容量限制、读写期限与消费确认，避免断开时丢弃未读取的响应。
- 通信客户端具备连接失败、限频启动引擎、同一请求重发、会话关闭与状态/重载/清除学习接口。超时返回明确状态，不把未知结果冒充一次新的提交。
- 引擎退出准备会先拒绝新的变更，再结束服务；正在组字或重建词库时拒绝退出准备。没有通过结束目标应用来卸载输入法。

## TSF 组字和候选界面

- 每个 TSF context 独立持有 Rime 会话、marked range、原选区、期望选区和修订号。同步按键编辑、异步候选与焦点清理只操作原 context。
- 数字/空格/鼠标选词、上下移动与翻页、Esc 恢复原选区、回车输出拼音；语言栏和候选菜单提供中英文切换、重新载入、清除本机学习及系统设置。
- 候选窗不激活目标外的窗口，使用带名称和调用动作的系统按钮；位置按 DPI 和屏幕工作区调整。回调复制与 COM 引用保护处理重入，窗口销毁清理句柄。
- 只读、加载中、密码/数字密码输入范围、禁用 context、安全模式和非当前输入目标不接管。外部文本/选区变化终止旧组字所有权。
- TSF 的完成通知在编辑回调之后到达，使用内容与期望选区比对区分本次编辑。不能只用“正在写入”布尔值。
- 引擎断连保留可见组字（包括已经选出的部分词语）；文本已经写入后的后续失败不重复插入。

## Windows 安装、注册和移除

- `OpenTypePinyinSetup.exe` 处理安装、修复注册和移除；从桌面调用时，只有机器注册子进程通过 Windows UAC 提升权限。
- 文件安装到系统 Program Files 下的独立版本目录。两种位数的 COM 类、简体中文 TSF profile 和输入/显示属性类别分别注册；当前用户的启用在原始未提升进程执行。不会把它设为默认输入源，也不启用其他用户的输入源。
- Windows 主程序和 Rime 引擎仍为 x64；额外编译 x86 TSF 客户端供 32 位应用加载，不复制第二套语音或 Rime 模型。构建入口按 x64、Win32 分别配置。
- 复制资源后记录待安装目录，再注册两种位数和提交当前目录。失败尝试恢复旧注册，恢复失败单独返回错误；取消 UAC、组字/部署繁忙、当前用户启用失败与清理未完成均有独立提示。
- 更新时不覆盖已加载的 DLL，也不结束目标应用。旧文件安排到系统重启时清理。仍加载旧 DLL 的应用可使用同一安装下、相同通信协议版本的引擎；协议不兼容时明确失败。
- 机器级注册的移除会影响其他用户，确认界面明确说明；所有用户的个人设置、短语和学习目录保留。系统“已安装的应用”中也有独立拼音卸载入口，移除主应用后仍可卸载组件。
- 注册和复制前检查固定安装目录及路径中的链接/重解析点，安装只复制自己的组件、固定 Rime 运行库和资源。未执行本机注册，也未请求真实 UAC。

## 桌面设置与同步

共享 `InputMethodService` 在正常 macOS/Windows 配置中投影设置；隔离配置不会改动系统输入法。Windows 页面区分文件安装、TSF 注册与当前用户启用，提供实际状态查询、失败提示、安装/更新、重新注册、移除和系统语言设置入口。安装过程中阻止启动应用更新。

Windows 已开放拼音短语账号同步，复用既有本机/账号隔离、离线队列、冲突、恢复和导入导出。设置原子投影到独立的 `dev.opentype.inputmethod/settings.json`；只同步用户明确添加的短语，不上传选词学习。

## 拼音与语音交接

- TSF 在其线程发布专用消息窗口，原生输入库绑定前台进程、窗口、线程、UIA 输入框与选区；没有 OpenType 活动端点时继续普通输入捕获。
- `prepare` 绑定原 context、组字修订与 TSF 选区。UIA 再核对同一个输入框和选区后才批准 `commit`。消息只有固定宽度的身份、时间、请求标识和取消事件名称，不含组字正文或 COM 指针，兼容 x64 到 x86 的调用。
- 等待响应在独立原生工作线程执行；Electron 定时读取状态。每次请求最长 1.5 秒，与录音时长无关。超时、关闭或取消会设置当前用户的私有事件，TSF 在执行前以及引擎计算后重新检查。
- 票据只使用一次，过期/切换 context/停用组件会释放。若引擎已计算完而请求被取消，保留可见 marked text，由下一次用户按键恢复输入，不在取消后异步提交。
- 确认提交完成后再次核对原 UIA 输入框，再捕获语音目标与上下文；复用听写、翻译、随便问、粘贴上一条及选区操作的准备/取消链路。已开始执行的原生文本写入不能回滚；取消不会继续启动语音或重放提交。
