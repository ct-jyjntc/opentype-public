# 安装启动与模型就绪验收 — beta.17

## 复现与修复

在独立临时目录实测旧实现：完整导入模型后删除 `tokens.txt`，`check()` 仍返回 `ready`；同时调用两次 `importBundle()`，结果分别为 `ready` 和 `ENOENT`。复现输出保存在随包 `evidence/reproduction.log`。

`SenseVoiceModelStore` 现在按设备、inode、大小和纳秒修改/变更时间核对文件。仅未变化的文件复用校验结果；变化后重新计算固定 SHA-256，避免设置页每秒完整读取约 240 MB。哈希前后核对身份，普通文件之外的类型不视为有效模型。

导入和下载共享任务，等先前校验结束后再修改文件，临时文件采用唯一名称。离线副本复制后再次校验，完成后原子改名；已正确的文件不改写。显式准备操作先用包内文件，无法从安装包取得的文件才下载；自动首启仅尝试包内模型。取消、文件写入失败及校验失败都转为可重试状态，轮询保留错误提示。

主进程先建立窗口/托盘再启动模型准备。普通音频与停顿分段均经过就绪门控，不再仅检查文件名是否存在。模型修复后清掉旧 worker，下次调用自动加载。模型设置 IPC 限定主窗口或专用听写设置窗口的主 frame。设置保存不依赖模型状态。

新增显式绝对路径 `--user-data-dir` 支持，日志也进入该目录。标准启动的路径不变；打包版继续忽略开发环境变量；独立配置不注册默认协议处理器。未获得单实例锁的进程不会执行启动初始化。

- 从本版 DMG 只读挂载、复制应用至专用临时安装目录，签名和 ASAR 与构建产物一致；实际 GUI 未注入替代 preload、未修改应用、未关闭 Electron 沙箱。
- 从空配置目录启动并完成真实引导；模型文件哈希符合固定值。权限对该应用身份已存在，本轮未验证首次系统授权弹窗。
- 正在运行时移走测试词表：模型页显示未就绪；模型目录不可写时修复明确失败；恢复可写后再次点击即恢复。缺模型时仍成功关闭整理并保存。
- 第二实例正常退出且未初始化服务；第一个实例仍可操作。两次正常 GUI 退出均对应宿主退出码 0。
- 重启跳过已完成引导，整理仍关闭，测试词典/音频保留；正确模型的 inode、修改时间、哈希未变。
- 在停机的临时配置中加入 macOS Tingting 合成录音，再由实际应用的历史“重新识别”入口调用真实 SenseVoice。结果为“明天下午3点开会讨论下个季度的产品路线图。”，原文与最终文字一致，正常退出后数据库结果和音频哈希通过。
- 独立 Node 测试使用实际包内模型和同一模型服务，在 macOS 禁止出站连接的沙箱中完成导入和修复；先用本机监听端口确认出站连接返回 `EPERM`，再验证两份真实模型文件与来源一致。
- 包内 worker 与模型通过真实 WAV/Ogg、75 秒以上合成语音、静音/损坏格式、取消/重启及空闲卸载测试。
- 17 个 JS/CSS/HTML 产物和两份模型与构建输出相同；严格深度签名、DMG 完整性、从挂载镜像复制后的签名验证通过。

## 验证边界与失败记录

最初尝试在外层 macOS 沙箱中启动整个 Electron 应用，因嵌套沙箱初始化失败而退出异常；一次改动测试策略后仍失败。两次异常测试进程均清理，后续使用新空目录和正常 Electron 沙箱重做。没有把该尝试记录为通过，没有以关闭 Electron 沙箱绕过。最终 GUI 验收没有强制断网，强制离线证据来自独立模型服务测试。

数据持久性核对脚本初次错误地读取了不存在的 `row.rawText`，实际识别原文位于 `modeMeta.raw_text`；更正核对字段后断言通过。此为验收脚本问题，未改动产品数据结构或识别结果。

本轮没有覆盖真实用户配置迁移、`/Applications` 原位升级、系统首次授权、真人音频/输入准确率、极端磁盘/断电恢复、完整断网 GUI、第三方应用注入、线上服务、正式签名公证及其他平台。取消能清理正常收尾的临时文件；进程被强制终止时的残留临时模型文件清理仍待专项处理。整体替代目标继续进行。
