# 功能补全清单

用户当前目标：尽可能替代 Typeless 和 Chatterfly，仅做 Windows 和 macOS 版本，并专注语音输入。继续保留 SenseVoice Small、本地优先、无产品录音时长上限和自然停顿提前识别。

## 当前范围：专注语音输入

系统拼音设置、输入法安装/注册入口、候选引擎、拼音短语与同步接口已从当前源码移除。听写、翻译、随便问、粘贴上一条和选区操作直接捕获目标输入框，保留原有焦点验证、取消准备与安全插入流程。

Skills、历史、语音词典及其读音提示、账号同步、设置备份仍保留。旧拼音个人文件与旧数据库表不主动删除，也不再初始化或使用；旧配置与设置备份中的额外字段会被忽略。已单独安装的旧系统输入源不会自动卸载。

以下保留此前开发与交付记录，其中拼音相关章节仅说明历史版本，不属于当前产品功能。当前移除工作的构建与独立验收结论以对应新版发布说明为准。

- 设置中的 Skills 页面：新建、编辑、复制、启用/停用、删除、排序、搜索。
- 内置清晰表达、聊天消息、邮件草稿、会议纪要、待办清单、开发需求、摘要、校对八个可编辑模板。
- 每个 Skill 可以限定听写/翻译/随便问、应用标识与网站域名；自动匹配按列表顺序，域名包含子域名，应用与网站条件同时生效。
- 首页与托盘支持手动选用、自动选择或不使用；手动选择优先，录音开始固定本次指令，不因中途更改设置混用。
- 受隐私保护的环境不自动选择；手动 Skill 只接收既有隐私规则允许的文字。全部 Skill 只生成文本，不运行外部操作。
- SenseVoice 的普通识别与停顿分段均在全文完成后交给同一 DeepSeek 处理步骤。Skill 失败或未配置服务时保留识别原文，明确报错，不把未处理原文冒充 Skill 成果。

- JSON 导入/导出。导入预览后新增，不覆盖现有项目；导入项的自动规则默认关闭。
- 历史保存 Skill 标识和名称，不保存指令全文。重试按原 Skill 的当前配置处理；原 Skill 已删除/停用时明确提示。
- 设置持久化、窗口间更新、主 frame IPC 及请求取消均已接入。

### 多快捷键与粘贴上一条

- 听写、翻译、随便问各支持最多三组绑定，设置页支持添加、替换与移除备用绑定。
- 所有绑定进入原生事件状态机，不再只读取第一个；同动作的备用键可结束已切换开启的录音，长按松手语义保持原动作归属。
- 绑定冲突按归一后的按键检查，包括修饰键顺序的等价组合；录入器继续隔离录音触发。
- “粘贴上一条听写”提供可选快捷键和托盘入口。读取最近完成且有文字的听写，优先使用用户编辑稿，不重新识别、不复制生成历史记录。
- 本次粘贴单独捕获当前输入目标，等待触发键松开，只尝试一次交付。失败保留可复制文字；Esc、新录音、休眠与退出会取消在途粘贴。

### 历史文字版本恢复

- 历史列表与详情显示本次 Skill 名称。

- 这类恢复不产生新的纠词建议，清除该历史的未确认候选；明确保留原始录音、识别原文和整理稿，便于来回选择。

### 录音设备与声音设置

- 添加录音提示音开关，默认关闭；麦克风实际打开后播放开始声，尾包停止后播放结束声，取消时播放取消声。声音在本机合成，不加载外部资源。
- 增加回声消除、环境降噪、自动增益独立开关，沿用原有默认开启值。每次录音固定当前参数，传递给真实 `getUserMedia` 约束。

- 分别提示无权限、设备不存在、设备占用等失败。
- 录音设备中途断开会进入停止与尾包收尾，保存并处理之前已收到的音频；断开导致尾包确认超时时，仍保留已收到的音频。历史记录保留设备断开标记。

### 阶段反馈与流式文字

- 浮窗区分收尾录音、保存、最后片段识别、文字整理、输入交付。
- 自然停顿识别后显示连续成功片段的尾部预览与片段数；失败缺口后的文字不会冒充完整连续结果。预览不写入外部应用。
- DeepSeek 改用 SSE，处理跨网络包的 UTF-8、CR/LF、data 事件与结束标志；明确完成且 `finish_reason=stop` 才接受最终结果。异常、截断、取消仍保留已有识别原文，不把部分生成当成完成稿。
- 文字工作台和选区面板显示可取消的流式结果；浮窗预览可在设置中关闭。已有最大输出 token 数仍是服务参数，超出时明确失败/回退原文，不是录音时长限制。
- 回答卡片和工作台提供轻量 Markdown 阅读视图（标题、列表、引用、代码块、表格、链接等），工作台可切回文本编辑。HTML 不执行，不加载嵌入媒体，链接只允许 HTTP(S)。

关键文件：`src/main/services/providers/text-stream.ts`、`src/shared/processing.ts`、`src/renderer/components/markdown.tsx`、`src/renderer/floating-bar.tsx`。

### 外放控制与多屏浮窗

- 录音时可保持外放、降到原音量的 20%，或静音；默认保持原音量。macOS 操作 CoreAudio 输出设备，Windows 操作 Core Audio 的默认播放/通信设备，不复用麦克风静音接口。
- 原生独立进程持有音量修改。停止收音、取消与退出释放；主进程崩溃导致 stdin 关闭时也尝试恢复。按设备 UID 和属性原值记录，只恢复仍等于本应用设置值的属性，手动调音量后停止接管该设备。
- 默认输出切换时先恢复原设备，再控制新设备。不支持音量控制的设备给出提示。设备断开时保留恢复记录，应用运行期间定期重试，退出后未恢复的设备在下次启动时重试。
- macOS 使用独立文件锁，Windows 使用当前用户/会话的命名互斥锁避免重复接管。Windows 原生进程在修改前原子写入私有恢复记录，处理设备回调、父进程退出及设备重连；具体范围见 [Windows 外放说明](windows-output-audio-2026-10-08.md)。
- 设置页独立显示外放状态、记录读写错误与待恢复设备，提供手动重试；录音期间禁用恢复操作。退出先给原生进程恢复时间，超时才强制结束。原生执行文件已加入构建与打包定义，本轮没有编译。
- 浮窗可放在当前输入窗口所在屏幕的顶部或底部，无法取得窗口时使用鼠标所在屏幕。拖动可记住归一位置；屏幕增删和工作区变化重新约束到可见范围。

关键文件：`native/output-audio/OutputAudio.swift`、`native/windows/OutputAudio.cpp`、`src/main/services/output-audio.ts`、`src/main/services/floating-bar-position.ts`、`src/shared/floating-bar.ts`。

### 独立词典同步

- 词典页提供独立、默认关闭的双向同步开关；本机词典不因登录而上传。启用时可选择复制本机词条，也可保持账号词库独立。
- 本机与账号词库明确切换；账号副本离线可用。按完整服务地址和账号隔离，注销回到本机词库；切服务地址先取消旧请求。识别和备份使用当前选中的词库。
- 客户端 SQLite 事务触发器持久记录新增、修改、重命名和删除，崩溃/断网后继续；后台拉取、上传、退避重试和手动同步均已接入。

- 仅完成源码；没有启动客户端或服务端，没有执行迁移、跨设备验证、测试、构建或部署。

### 拼音与语音交接

- 听写、翻译、随便问、粘贴上一条和选区操作接入组字提交握手；右 Command/Fn 等修饰键快捷键不再依赖拼音组件接收普通 keyDown。
- 先绑定原应用、输入框与拼音会话，再请求提交原组字；收到提交完成确认后捕获语音目标及上下文。临时消息不携带组字正文、凭据或历史。
- 新增可取消的输入准备状态；等待时不开麦克风，松开长按快捷键或停止会取消启动，旧请求不能启动后续录音。超时、旧组件、输入源/选区变化有明确提示。
- 首页试听保留独立预览，不读取外部上下文；选区准备、退出、锁屏/休眠及更新忙碌状态已接线。已提交的拼音不因随后取消语音而回删。
- 只完成源码，没有运行或打包；组件需与新的输入辅助库一起构建。详见 [拼音语音交接说明](pinyin-voice-handoff-2026-10-08.md)。

### Windows 剪贴板独立恢复

- 在剪贴板锁内核对序列号和窗口所有者，再恢复原内容；用户的新复制优先保留。临时占用或部分设置失败保留副本重试，前一次未恢复时不叠加新交付。
