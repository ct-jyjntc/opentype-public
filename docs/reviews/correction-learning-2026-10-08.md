# 可审核的历史纠词学习

beta.11 按[参考材料中提出的次序](reversing-deliverables-assessment-2026-10-08.md)实现历史修改候选、明确确认与来源核对。没有执行第三方归档脚本，没有把归档的伪代码当作可运行完整源码。

## 实际行为

只有用户在普通听写历史主动保存修改后才触发本机候选提取。待审核内容由词级差异得出，不调用网络模型，也不监听其他应用。默认生成建议，可在个性化设置关闭；关闭不自动删除已有词条。

词典页展示“误写 → 建议词条”、来源应用和时间。用户可以查看来源历史、忽略、审核并修改词条和误识别提示；确认后加入本机词典。DeepSeek 整理继续使用词典上下文参考，模型权重不变，不做无条件同音替换。请求最多采用最近添加的 200 个词条，超出时界面提示；其余仍存本机。

审核说明明确：启用 DeepSeek 时已确认词条与提示会随整理请求发送，候选来源全文不会因此发送。待确认内容只在本机。词典中的“历史纠词 · 查看来源”打开实际来源记录，原始识别文本与用户修改可对照。

## 数据与并发边界

- 新增 `correction_candidates` 本机表，记录最小误写/建议词条、来源 ID、编辑版本摘要和处理状态，不额外存整段历史。
- 编辑和新建议在同一个 SQLite 事务写入。只对完成的普通听写生成；翻译、指令、失败记录、受保护/已脱敏输入及当前域名黑名单记录跳过。
- 确认再次校验来源、编辑摘要和隐私条件；重复确认幂等。同名大小写重复词不会覆盖手动词条的拼写、提示或来源。
- 数据库触发器使重试/同步更新/新编辑后的旧候选失效。删除来源级联删除全部候选及对应处理记录；单条、本机清空和真实远端删除路径均验证。
- 已明确确认的词条独立保留，来源外键置空，界面显示来源已删除。从词典删除可撤销，不回滚历史修改，也不会重新推荐同一来源中已经处理过的建议。
- 候选提取使用有计算量边界的词级差异：每处 2–24 字符、至多 6 个词段，单条最多 20 条。纯标点/空格、数字、单独新增/删除、明显代码/链接/地址和大改写尽量跳过。超过十万字符不分析。
- 提取不是专名识别器，部分短句改写仍可能成为候选，所以始终需要用户审核。字典提供参考不等于实测识别率改善。
- 原先历史保存静默截断十万字符，本批改为完整保存；超过一百万字符明确拒绝且保持旧记录。空字符串编辑通过空值判断正确显示，不再回退显示旧识别稿。这不是录音时长限制。

## 验证

最终 `npm run verify:all` 退出码 0，日志 `tmp/correction-learning/verify-all-final.log`，包括原有客户端、原生、服务端、云端删除和网络回归。

新增 `scripts/test-correction-learning.ts` 共 15 组：旧词典迁移、完整名称/多个更正、噪声编辑排除、显式保存、确认幂等、词典实际进入整理请求、来源删除、忽略/非法输入、重复词保护、开关/模式/隐私、过期建议、撤销、长/空编辑、重启与清空、分页及真实远端删除。使用真实 SQLite 和临时目录；整理网络使用 MockAgent，没有发送真实用户内容或凭据。

桌面 Electron 测试补充真实 IPC handler 的开关、编辑、提议、修改后确认、来源字段及撤销路径。实际界面在全新隔离目录使用合成历史，完成以下过程：

1. 将 `Please use Opentipe and SenceVoice today.` 改为 `Please use OpenType and SenseVoice today.`。
2. 保存后显示两条待确认建议，词典仍为空。
3. 确认 OpenType，忽略 SenseVoice；词典仅新增 OpenType 与误写提示。
4. 从词条打开来源，核对用户修改与未改动的识别原文。
5. 退出重启后，已确认词条、来源链接和忽略决定保持。

约 6.3 万字的本机合成文本候选提取约 32 ms，仅单次开发环境观察，不是录音延迟或全面性能分布。真实词典改善质量尚待语料对照；本批不声称提高了真人识别准确率。

`npm run pack:beta`、严格 codesign 检查、DMG 校验、包内 18 个 JS/HTML/CSS 与 dist 字节比对通过。交付目录 `release/testing/0.2.0-beta.11/` 含安装包、真人清单、截图、验证报告和校验和。没有替换 `/Applications` 安装，也没有修改用户真实历史/词典目录。
