# macOS 拼音输入组件：源码实现

本批只读写代码和依赖资料，没有执行编译、测试、类型检查、GUI 验证、系统注册或打包。Rime SDK 仅下载到依赖缓存并读取归档/链接信息；未运行其中的程序。现有 beta.17 安装包及系统输入源没有改变。

## 已接入的功能

- 独立 `OpenType Pinyin.app`，以 InputMethodKit 控制器接收系统输入会话，使用 Rime 1.13.1 核心与固定版本的公开简体拼音基础词库。
- 全拼、简拼、整句转换；5/7/9 个候选，数字/空格确认、上下移动、翻页、鼠标选择。回车输出原始拼音、Esc 取消；切应用/输入源时结束原会话，避免候选悬挂。
- 候选窗使用不激活应用的 NSPanel，定位到输入光标所在屏幕并约束可见区域；候选按钮有无障碍标签。Rime UTF-8 光标偏移转换为 IMK UTF-16 位置。
- zh/z、ch/c、sh/s、n/l、f/h、an/ang、en/eng、in/ing 八组模糊音；中文标点及左/右引号轮换；常用拼音对应本地表情候选，通过点击输入。成对引号采用轮换方式，不自动把光标移进成对括号。
- Caps Lock 英文直输，输入法菜单也可切换英文。Command/Control/Option 和 Fn 字母/空格组合继续传递；原有全局语音监听保持独立。
- 后续交接批次增加本机组字提交握手：语音快捷键先结束原拼音组字，再捕获输入位置；等待时可以取消，目标变化使请求失效。详见 [拼音语音交接说明](pinyin-voice-handoff-2026-10-08.md)。
- 可关闭个人选词学习，关闭后不使用个人学习词库。系统输入法菜单有明确确认的清除学习入口，保留手工短语和语音数据。
- 设置 → 拼音输入：偏好、短语 CRUD、搜索、UTF-8 TSV 导入预览/合并、导出。短语与拼音联合去重，权重可编辑；修改绑定读取时的数据版本，拒绝覆盖其他窗口/进程的后续保存。

## 数据与生命周期

独立目录为 `~/Library/Application Support/dev.opentype.inputmethod/`。后续同步批次将桌面 SQLite 设为偏好和短语的权威存储，再生成供原生读取的 `settings.json` 副本；原生组件将选项转换成 Rime 配置和短语表，在 `rime/` 中保存编译词库和学习数据。原生输入法不读取桌面主配置、账号、凭据、语音历史或整个输入框正文。网络同步由桌面主程序的独立拼音同步服务处理。

同一用户只有一个 Rime 数据库持有者，文件锁随进程退出释放。词库准备使用串行后台队列，仅在没有活跃会话时重建；准备期间显示状态并让键盘文本交给应用，不阻塞主输入线程。失败保留设置和词库，并提供菜单重试。后续批次增加原生配置监视，在当前组字结束后重载，也可从输入法菜单重载。

拼音自定义短语与语音词典是两份数据：前者需要拼音和权重，后者的释义用于语音纠词。两者已有独立的账号同步开关和存储契约；个人选词学习不上传，并按词库范围隔离。详见 [拼音同步与原生重载](pinyin-sync-2026-10-08.md)。

## 安装、更新与移除

桌面设置提供安装/更新/重新注册/移除入口。构建出的组件随安装包携带；用户确认后复制到 `~/Library/Input Methods/OpenType Pinyin.app`，由用户在系统设置中添加/选择。首次注册或移除后系统可能需要重新登录刷新菜单。隔离桌面配置不操作系统输入源。

更新前先在临时路径复制并校验组件签名，要求当前输入源已切换到其他输入法；原组件收到停止请求后再次核对当前输入源，再释放引擎。替换采用旧目录暂存、新目录就位，重命名失败尝试回滚；注册失败保留已复制组件并提供重试入口。

移除前要求切换输入源，停用本组件并等待引擎停止，再将应用移到废纸篓；数据目录保留。操作只针对固定的 OpenType 输入法包，先校验包身份，不覆盖未知应用。语音主应用不因移除拼音组件而退出。

## 构建与依赖

`scripts/build-input-method.sh` 已接入 `scripts/build-native.sh`，electron-builder 增加独立输入法资源。构建时获取带固定 SHA-256 的官方 macOS universal Rime SDK，只提取核心库和头文件；不执行归档中的程序，也不打包可选插件。字典、schema、表情和许可证随源码及组件保存。首次依赖获取需要网络，安装后的拼音引擎使用本地资源。

完整来源和许可证在 `native/input-method/resources/licenses/NOTICE.md`。基础词库直接来自公开项目，没有采用用户逆向材料中尚未还原的 Chatterfly 私有词库。这不代表词汇覆盖、选词排序或输入质量已经与 Chatterfly 相同。

后续仍需补齐其他平台实现，以及整体源码衔接。没有将运行验收作为本轮继续开发的条件，也没有将未经运行的组件宣称为已经可安装使用。
