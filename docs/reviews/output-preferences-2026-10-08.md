# 中文输出偏好与应用语气：实现和验证

本批对应 Chatterfly 的标点/间距与 Typeless 的应用语气方向。参考材料沿用此前的[本机交付材料核对](reversing-deliverables-assessment-2026-10-08.md)，没有执行归档里的脚本，也没有把伪代码视为完整后端实现。

## 行为

- 个性化设置增加中文标点、间距、默认表达方式和应用规则；旧配置默认不做本地格式修改。
- 中文标点只转换中文相邻的既有英文标点，不猜测缺少的逗号或句号。间距仅处理汉字与 ASCII 英文/数字交界，保留换行。
- 格式调整不依赖模型或网络；成功的普通听写在最终存档和插入前处理一次。失败、外部交付、翻译、语音指令不修改。识别原文独立保存。
- 对代码围栏、行内代码、引号内容、明显的代码/缩进行、链接、邮箱、路径、文件名和小数提供保守保护。规则不是完整编程语言解析器；模糊技术文本可能保留原格式，无法保证任意语法都识别正确。
- 语气选择由已启用的 DeepSeek 整理使用，不用本地替换词假装改写；表达方式优先于额外写作说明中的语气。数字、事实、名称、代码、链接和完整信息不应因语气变化而改变，真实效果仍需语料验收。
- 应用以 bundle ID 精确匹配，显示名称只用于界面。未匹配使用默认表达方式。规则上限 50，选择列表包含常见应用、已保存规则及最近 500 条历史出现的应用；不依赖网站跟踪或扫描其他应用内容。
- 录音开始时读取偏好并固定目标；历史重试读取该历史的原目标应用和当前偏好。重试在异步读取个性化之前固定识别服务，取消后不再调用服务。

## 已完成验证

`npm run verify:all` 退出码 0，包含类型检查、完整现有回归和新输出偏好用例。证据：`tmp/output-preferences/verify-all.log`。

- 新增 8 组格式/规则场景：迁移和非法配置、精确匹配、选项独立、数字/版本/百分比、链接与代码保护、换行和重复处理、模式和原文保护。
- CaptureSession 共 15 组，其中新增 4 组：偏好快照和原目标重试、增量链路、重试服务切换/取消、取消后的迟到个性化异常。
- DeepSeek 回归共 10 组，其中新增 2 组：只发送已选表达方式；翻译/指令不接收普通听写风格。请求与响应使用 MockAgent，不能据此评价真实模型质量。
- 真实 Electron 设置接口验证新字段保存、无效写入保持原设置、删除规则；真实 UI 验证保存中文标点和空格、默认简洁、微信口语和邮件正式、额外说明，退出重启均保留，移除微信规则后不影响邮件。
- `npm run test:output-preferences:host` 退出码 0。真实 SenseVoice Small 关闭整理，整段与增量识别各验证一次，并分别从历史重试；不调用真实麦克风或系统粘贴。

真实模型样本来自 macOS Tingting 合成语音：“明天下午三点开会，检查八十五个文件。”

| 路径 | ASR 原文 | 本地格式输出 |
|---|---|---|
| 整段、增量及两次历史重试 | 明天下午3点开会检查85个文件。 | 明天下午 3 点开会检查 85 个文件。 |

ASR 未输出“开会”后的逗号，本地格式步骤没有擅自补出。此样本证明链路与数字间距生效，不是识别准确率或延迟分布测试。原始证据：`tmp/output-preferences/real-model.json`。
