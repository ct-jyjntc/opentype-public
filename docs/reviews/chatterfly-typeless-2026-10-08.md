# Chatterfly 与 Typeless：OpenType 的实现与验收方向

日期：2026-10-08。参考对象由用户确认：[腾讯 Chatterfly](https://chatterfly.tencent.com/) 与 [Typeless](https://www.typeless.com/)。本机核对版本：Chatterfly 1.0.5.13395、Typeless 2.8.1。只读查看偏好设置，没有修改两款应用的配置或读取私人语音历史。

## 实际观察与边界

| 来源 | 实际看到的功能或说明 | 不能由此推导的结论 |
|---|---|---|
| Chatterfly 本机设置 | 按住或短按语音输入、单独的指令模式快捷键、麦克风选择、交互声音、录音时静音其他音频 | 尚未用相同真人音频测量识别效果和延迟 |
| Chatterfly 本机设置 | 语音增强识别的上下文提示说明；标点偏好、数字和英文间距偏好 | 未独立审计其隐私实现和自动学习算法 |
| Chatterfly 本机设置 | 拼音输入、模糊音、候选表情、成对标点、词库同步与本地词库导入 | OpenType 尚不是完整拼音输入法 |
| Chatterfly Skills 页 | 说明开启 Skill 后结合当前输入场景选择并改写润色 | 当前查看未验证任何具体 Skill 的执行效果 |
| Chatterfly 官网 | 宣传碎片表达整理、场景理解、轻声和噪声输入、个人词汇和跨应用使用；macOS/Windows 下载入口 | 宣传描述不等于公平性能评测 |
| Typeless 本机设置 | 听写、翻译、问任何问题独立快捷键，允许添加另一组快捷键；翻译目标与语言变体；麦克风、交互声音、录音静音、外观、启动与 Dock 选项 | 未验证全部语言或所有应用的可用性 |
| Typeless 本机首页及个性化页 | 面向邮件、聊天、文档等使用场景；独立个性化页面 | 未取得其自动学习后的效果对照 |
| Typeless 官网（前批核对） | 去赘词、重复和改口，列表、个人词典、应用语气、翻译、选中文本编辑等 | 不能把官网功能清单当成 OpenType 已实现的清单 |

## 结合方式

1. **语音基础先稳定。** 保持 SenseVoice Small 本地识别，停顿时提前处理，结束后合并全文；快捷键录入与全局触发隔离，取消和失败恢复可预测。保留无限制的产品录音时长，内部切片不结束录音。
2. **整理全文时理解场景。** 借鉴 Typeless 的改口、列表、邮件和聊天表达，并结合 Chatterfly 的中文标点与中英文间距偏好。由用户明确选择是否开启云端文字整理；本地识别不依赖云端。
3. **词典与风格分别可控。** 专业名词、缩写和个人词汇应能添加、修改和删除；显式写作偏好可以查看和关闭。自动学习后续必须提供可审核的候选词，不把自动学习宣传成当前能力。
4. **指令先让结果可检查。** 听写、翻译、选中文本编辑分别有清晰入口；涉及外部操作时说明将要执行的动作，避免错误识别直接产生副作用。
5. **数据处理范围说清楚。** 历史、录音、云端副本应有一致的删除语义。beta.6 先修复本机记录与录音生命周期；跨设备删除传播仍未完成。

完整拼音输入法、系统候选窗和各平台安装并非本批实现；仍在完整差距清单中保留，不能因此宣称已完全替代 Chatterfly。

## 统一实测方法

三款软件使用同一台 Mac、同一麦克风、同一环境，各场景至少三次；只同时运行正在测的一款，避免全局快捷键冲突。分别记录冷启动、已加载模型、整理开启/关闭；从停止动作到文字在目标输入框完整出现计时。

固定场景：中文口语改口、真实重复、技术名词、中英混说、列表、短句、连续 10 分钟、自然停顿、最后一个字立即停止、轻声、背景噪声、断网、取消后马上重录。记录漏词、重复、擅自添加含义、标点、尾句、输入位置和等待时间。先检验全文完整，再比较速度。既有 36 秒合成语音的性能结果只用于 OpenType 前后对照，不能当成三款产品的胜负结论。
