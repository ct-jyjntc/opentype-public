# 网络传输与账号隔离修复

版本：0.2.0-beta.9。日期：2026-10-08。

## 问题与变化

beta.8 仅约束 SyncEngine；登录、令牌刷新、自定义语音上传、兼容 API 和服务端转发仍可能使用公网 HTTP。自定义语音服务还会直接取账号服务令牌，不区分两者地址。认证刷新在读响应正文前检查了会话，正文迟到时却缺少第二次检查，可能在退出后恢复旧账号。

本批统一敏感请求的地址验证，并补齐账号状态检查：

- 客户端认证、同步、历史 API、语音上传、文字整理和引导调查使用受保护的请求入口。只允许 HTTPS 或本机回环 HTTP；拒绝 URL 中的用户名、密码、查询参数和片段，避免将秘密混入服务地址。校验先于获取账号令牌和发起请求。
- 凭据请求不跟随重定向，收到 3xx 明确拒绝，不将重定向响应当成成功登录或成功结果。TLS 证书验证保持开启，没有放宽系统证书信任。
- 自定义语音服务只有与账号服务的完整基地址一致时才可取得登录令牌，包括协议、主机、端口和路径。用户明确设置的语音 API Key 单独使用；更换语音服务地址且未提供新 Key 时清空旧 Key。
- 服务端与网关的音频、LLM 和邮件转发使用相同地址策略。服务端 fetch 设置 `redirect: error`，不把音频、原文、验证码或凭据转发到 Location 指向的地址。服务端部署仍可只复制 `server` 目录；纯策略模块位于该目录，客户端与网关共用它。
- 邮件未配置及失败日志不再输出收件人、验证码正文或 API Key。测试服务进程显式禁用真实邮件配置。
- 公共模型与版本信息下载使用独立的无凭据 HTTPS GET。允许 HTTPS CDN 跳转和签名查询参数，拒绝降级到 HTTP、嵌入凭据及无限重定向。模型仍进行既有固定大小和 SHA-256 校验。
- 新安装默认不配置云端账号地址，本地功能仍可使用。旧地址不被静默改写；非法或公网 HTTP 地址会显示说明。账户页在地址有效并保存前不允许提交登录。
- 新登录、PKCE 登录和退出都会使旧认证请求失效。读取迟到正文后再次检查会话，旧刷新或旧登录不能恢复被退出的账号，也不能覆盖更新的登录。旧 provider 持有所属认证实例，不通过后来替换的全局实例取新服务器令牌。

## 验证

- 完整 `npm run verify:all` 通过，包括原有客户端、网关、服务端、原生输入、录音与云端删除回归。
- 新增客户端网络检查 15 组：HTTPS/回环正例、非法地址、登录/注册/刷新/退出、PKCE、兼容 API、自定义/OpenAI 音频、不同服务的令牌隔离、地址变更 Key 清理、五种重定向、真实迟到 HTTP 正文、真实自签名 TLS 拒绝及公共 CDN 跳转限制。
- HTTPS 成功响应与公网拒绝测试使用 undici MockAgent；迟到认证响应使用本机真实 HTTP 服务。TLS 测试临时生成自签名证书，确认服务器收到的 HTTP 请求数为 0，没有向系统安装或信任证书。
- 新增服务端检查 4 组：明文请求在 fetch 前被拒、模拟 HTTPS 正常转发、实际本机 HTTP 307 无跨端点重发，以及邮件日志不含敏感内容。邮件成功分支由假 fetch 验证，没有发送邮件。
- 既有 8 组 DeepSeek 整理回归继续通过，包括官方地址限定、独立密钥、无音频传输和重定向拒绝。
- 实际 Electron 使用新的隔离配置目录启动：默认云端地址为空、登录按钮禁用；保存公网 HTTP 地址被拒，检查落盘文件确认旧值未变；保存合成 HTTPS 地址后登录按钮恢复，退出重启后地址和状态均保留。未输入密码、未发起真实第三方登录。
- 打包、严格递归 codesign 和 DMG 验证通过，ASAR 内 18 个 JS/HTML/CSS 文件与当前构建逐字节一致。校验与截图随 release manifest 保存。

日志：`tmp/network-policy/targeted.log`、`server-network.log`、`verify-all.log`、`package.log`。测试只使用合成凭据、临时证书和临时账号，不读取或修改用户真实凭据与历史。

## 验收边界

本批没有部署线上 HTTPS 服务、配置生产邮件，也没有完成 Developer ID 签名或公证。真实用户的端点、代理和企业证书环境未验收。外部浏览器打开的网站仍由浏览器负责其后续页面和跳转；本报告针对应用及配套服务主动发起的请求。

目前的地址策略允许本机回环 HTTP，不允许普通局域网 HTTP；部署在其他设备上的服务需要有效 HTTPS。TLS 正例通过模拟 HTTPS 响应验证协议；本批没有向真实第三方服务发送凭据或语音。系统自签名证书拒绝检查属于真实 TLS 负例。

中文表达偏好、可审阅纠词学习、真实多设备/麦克风/跨应用验证、云端整体清理语义和正式分发仍待完成。整体替代目标保持进行中。
