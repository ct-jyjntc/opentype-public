# beta.14 输入框纠词建议：实现和验证

参考 [用户材料中的编辑跟踪职责](reversing-deliverables-assessment-2026-10-08.md)，在既有历史纠词审核链路之上实现从本次听写输入框生成建议。没有执行第三方归档脚本，也没有声称恢复其完整学习算法。

## 实现与数据边界

- 独立 `learnFromInputEdits` 开关，默认关闭。只有普通听写、自动插入、已核对实际交付并成功写入历史状态，才可转移原生目标给检测器；翻译、指令、预览、未确认/失败插入均不启动。
- 原生 `beginInputObservation` / `readInputObservation` 复用已验证的句柄，保持同一个应用和可编辑元素。读取前检查权限、前台、保护属性及全部祖先网页来源；页面导航、切应用/输入框、选区越界即结束。
- 为核对范围，会在本机临时读取同一字段的当前值，与捕获时的前后文字逐字比较；任一外部范围变化即拒绝。只返回本次插入区域的字符串，不把整份字段内容、句柄或后续无关输入交给 renderer、数据库或网络。原始目标快照和当前核对值仍会短暂存在于原生进程内存，不能宣称完全不读取字段外围。
- 每 250 ms 检测，稳定 1.5 秒后生成候选，最多一分钟。边界以 UTF-16 处理；插入内容上限十万、字段一百万字符仅用于可选学习分析，不限制录音或识别长度。不轮询系统登录项设置。
- 关闭开关、下一次录音、明确回答替换、锁屏/休眠、退出释放句柄。原生还有独立超时。检测器只持有一个目标，回调失败、过期来源、重复停止都能收尾。
- SQLite 仅新增候选词对、来源类型和用于重新检查隐私的来源域名；不保存修正后的整段内容，也不更新历史文本/同步状态。保存时条件检查完成状态、原识别结果、没有手工历史编辑及已验证交付。删除、重试、历史修改后的迟到结果不能复活记录。
- 稳定候选再次变化或撤销时，先清除旧的待审核候选。已确认词条不会自动撤销；同一来源的忽略和确认决定保留。切目标前尚未稳定的修改不生成建议。
- 自动输入观察比主动保存历史更不确定，因此在词级差异之后增加拼写距离过滤，拒绝大幅替换；仍不是专名分类器，可能漏报或产生不合适的建议，必须审核。历史纠词保持原有逻辑。
- 确认再次校验来源版本及父页面域名黑名单，词典标记“输入框纠词”。来源历史保留原稿；词条仍只供已启用的 DeepSeek 整理参考，不训练 SenseVoice 权重。

## 验证

完整 `npm run verify:all`，最终日志 `tmp/input-corrections/verify-all-final.log`。新增 `test-input-corrections` 12 组，包含稳定窗口、候选撤销、明确审核、禁用/模式/隐私、超时/切目标/错误释放、新捕获、父页面黑名单、历史修改/重试/删除、非词汇编辑、真实 SQLite 重启及 beta.13 旧候选表迁移。原有历史纠词 15 组保持通过，CaptureSession 增至 23 组，验证所有权转移与保存失败不启动。原生测试补齐 UTF-16 边界、前后文变化、大小边界。

首轮自动化发现整句改写会被原有提取器拆成几组词条；增加输入框专用拼写差异过滤后通过。没有删掉失败用例或把误建议解释为通过。

实际测试：

1. 通过 CUA 操作隔离 AppKit 编辑器。生产 CaptureSession、InputDelivery、Swift/Koffi 完成跨进程插入；原生确认后开始观察。
2. 模拟语音固定输出 `Please use Opentipe and SenceVoice today.`。显式标注的夹具场景在自己的文本控件内模拟改为 `Please use OpenType and SenseVoice today.`；原生返回的修改区域不含前后的 `Native` / `After`。真实 SQLite 生成两个 `input_edit` 候选。
3. CUA 定向键盘操作时，测试工具有时未保持实际前台，捕获或检测按 PID/前台条件拒绝。成功候选来自上述夹具模拟编辑，而不是这几次定向打字；两类结果分别保留，不将其称为真人验证。
4. 原生夹具关闭后，将其临时数据库复制到全新测试配置目录，启动实际 OpenType 前端。核对两个输入框来源候选，确认 OpenType、忽略 SenseVoice；正式词典只有一个词条。点击来源仍显示未改动的听写原稿。
5. 独立开关默认关闭；通过实际设置开启后正常退出，重启核对开关保持、已确认词条及忽略状态保持，新文案显示正确。没有读取或改动真实用户目录。

证据位于 `tmp/input-corrections/`：`native-ui-results.json`、`focus-boundary-results.json`、各 UI 日志，以及原生纠错、待审核建议、原稿保持、重启词典和设置截图。成功原生场景使用合成语音和夹具编辑，不验证麦克风、实体键盘或模型质量。
